# T17 · 生成可跳过的单条追问并处理迟到结果

GitHub：[#18](https://github.com/brycezhang/timenook/issues/18) · 状态以 GitHub 为准。
阶段：S2

## 交付结果

当前片段转录就绪后，可出现一条中性追问；用户可改写、跳过、继续讲或结束。

## 验收条件

- [ ] 输入固定当前故事转录、实际问题/历史与本人偏好，先规则排除禁问、不适用及重复，不扫描其他故事推断事实。
- [ ] 校验 ask/finish、question、intent、sourceRefs、reasonCode；未知引用/多题/诱导或重复结果拒绝并提供经审校候选或直接完成。
- [ ] 用户换题/结束/偏好变更/撤回后，旧结果不能替换界面；实际显示文本另存快照。
- [ ] 主动额度按套餐配置，系统重试不重复扣额；记录转录就绪到追问时延，任何失败不阻塞原声保存及整理。

## 实现边界

复用 T03 输出校验/提示词与 T15 任务机制；一条可选追问，失败可用审校候选或结束。固定首版额度，不扩展多模型编排和跨故事画像。
