# MP08 · 故事编辑、回听与随时归章

状态：ready-for-agent；GitHub [#174](https://github.com/brycezhang/timenook/issues/174)，父规格 [#166](https://github.com/brycezhang/timenook/issues/166)。父规格：[小程序全量重构](../spec.md)。

## 交付结果

用户查看和编辑真实故事、拖动进度条回听，并把未归章故事随时归入任一章节或跨章移动。

对应差异：F14、F15。主责画板：`Stories`、`Story`、`StoryEdit`、`StoryProcessing`、`StoryFailed`、`StoryUnassigned`、`UnassignedStories`、`AssignStory`。详见[画板对照表](../DESIGN-MAP.md)。

## 验收条件

- [ ] 列表、详情、整理中、失败、文字编辑和未归章状态逐一对应画板；正文、照片、原声与章节来自当前项目。
- [ ] 原声复用现有播放/暂停/拖动进度和精确时间，同故事补录保留原故事身份和所有片段。
- [ ] 从详情、未归章列表和任意章内可归章/移动；移出入书与未归章的状态可区分并可恢复，均保留素材。
- [ ] 文字编辑只负责保存；补录从详情进入，故事卡整块可点，删除重复功能入口。
- [ ] 失败仍可回听已保存原声并重试，整理中可离开；保存、归章和跨项目返回不串用状态。
- [ ] 本票全部主责画板完成设计与原生 UI、交互对照，记录 390px/320px、真实入口、截图与差异处理；不留死入口或用样例数据冒充业务。
- [ ] 实现、相关检查、原生验证及外部待验分别记录，改动与测试只覆盖本票实际边界。

## 数据与契约边界

本票按新方案直接修改相关前后端、共享契约和数据库。开发数据可破坏性重建，不做旧模型兼容、双写或旧接口别名。影响现有网页/后台消费者时同步适配，不扩展视觉范围。

## 测试决策

故事版本、素材引用和章节唯一归属集成测试；原生播放器拖动、编辑保存、无章→归章→跨章→暂不入书完整路径。

复用现有测试入口，优先验证公开行为；数据库约束使用真实 PostgreSQL/Redis。外部待验不视为功能缺失，已实现能力与未验环境分别说明。
