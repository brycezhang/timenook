# Remento 产品功能参考

核验日期：2026年10月14日。范围为Remento Life Story Book的官网、官方帮助中心与印刷指南。该表描述公开产品能力，不代表已购买或实际体验全部功能。

Remento的核心成果是文字、照片与本人原声共同构成的人生书。其公开流程以题目触发录音、语音整理和书籍交付为主。岁月成书使用微信小程序，定价999元，服务一位父母与一位购买子女。

| 功能环节 | Remento公开说明 | 岁月成书MVP要求 |
| --- | --- | --- |
| 赠礼与角色 | 可给亲人创建Life Story Book，购买者作为Host支持Storyteller；也有礼品卡模式。[赠礼指南](https://help.remento.co/en/articles/8634394-guide-to-gifting-remento) | 子女创建项目并邀请一位父母，或同机协助；一个固定套餐 |
| 讲述入口 | 通过邮件或短信链接进入录音，不要求下载App或记忆密码。[录音说明](https://help.remento.co/en/articles/8365951-how-do-i-record-a-memory) | 微信邀请和一次绑定，后续直接回到项目；无需设置产品密码 |
| 问题引导 | 提供题库，并可按周发送问题，允许自选记录节奏。[产品流程](https://www.remento.co/how-it-works) | 基础题库、换题、自主记录；结果在项目页查看 |
| 照片与故事 | 照片可以触发回忆，也可在录音后加入故事。[FAQ](https://www.remento.co/faq) | 复用照片上传，支持看照片讲述及成文后补图；照片非必填 |
| 记录媒介 | 可录音频或视频。[录音说明](https://help.remento.co/en/articles/8365951-how-do-i-record-a-memory) | 仅音频，短段录制与补录 |
| 成文与编辑 | 支持清理转录、叙事稿、第一或第三人称、长度调整及文字编辑。[FAQ](https://www.remento.co/faq) | 固定第一人称自然叙事；原声、转录、稿件分别保存；基础文字校对和本人确认 |
| 家庭互动 | 提问、投票、共享及回应可由家人参与。[产品流程](https://www.remento.co/how-it-works) | 两用户角色，仅子女协助；无家庭提问、投票、评论或多人成员 |
| 书稿与生产 | 设置封面、审核入书故事并预览完整PDF，再确认生产。[印刷指南](https://resources.remento.co/printing-a-book/ordering-your-book) | 一个封面和内页模板，完整PDF校对，必要排版问题由运营处理 |
| 原声二维码 | 书中的二维码关联相应故事原始录音。[印刷指南](https://resources.remento.co/printing-a-book/ordering-your-book) | 每篇故事起始处一个二维码，绑定确认版本，访问受父母授权控制 |
| 实体权益 | 标准购买包含首本实体书，也可购买额外份数。[官网](https://www.remento.co/) | 999元含一本实体书及约定配送，无加印或超页交易 |
| 创作与资料访问 | 创作权益按期提供；不续订仍可访问已有资料，并可下载备份。[FAQ](https://www.remento.co/faq) | 一次性套餐，制作、在线访问和资料保留期限分别公示；PDF下载、客服完整资料导出 |
| 长期服务 | 官网声明永久访问已有记忆；具体服务和权益由其条款定义。[官网](https://www.remento.co/) | 按可履约期限提供服务和完整导出，不承诺永久云访问 |

## 适用说明

Remento公开流程不能直接证明实时AI语音访谈或动态追问的具体实现。岁月成书的当前故事内简短追问是本项目自身的需求。

Remento的赠礼、记录和成书属于不同服务阶段。岁月成书也应分别说明邀请参与、内容准备、校对确认、生产和收货的时间。

Remento的海外价格、订阅周期、退款条款、纸书规格和二维码访问方式不构成岁月成书的销售承诺。岁月成书采用999元、单本交付及本地生产和权限方案。
