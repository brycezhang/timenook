# 小程序礼物由指定收礼人领取

2026-11-14 新增渠道已购礼物入口，见 [ADR 0021](0021-channel-gifts-and-partner-admin.md)。后台按购买者手机号录入购买记录，小程序确认赠礼关系和书名后创建同一本故事书及首本权益，再进入本篇指定收礼人流程；送给自己直接进入故事书。待用礼物长期有效，新增礼物提醒和后台更正边界按渠道规格实施。

「时光故事」在小程序统一采用送礼入口，包括送给自己。关系必填，可选爸爸、妈妈、爷爷、奶奶、自己或自定义。付款为购买者创建一个项目和首本实体书权益。购买者通过微信送出电子礼物卡，项目成员完成书稿后填写收货地址并提交印刷。

送给自己时，当前登录账号同时是购买者和主讲人，付款后直接进入故事书，无需给本人填手机号、分享或领取。送给他人时，收礼人同时是书的主人公。购买者在付款后指定收礼人的微信绑定手机号，持有当前礼物卡并用匹配的已验证账号明确接受，才成为同一个项目的成员。每份礼物只领取一次，原领取者可重开卡片进入自己的项目。领取前可更正手机号并重发，原卡失效。项目邀请仍用于让其他家人参与同一个项目，和礼物领取各自记录。

购买者可以在领取前整理书名、话题和照片。领取只改变礼物状态和收礼人的项目成员关系，付款、项目、首本权益和印刷规则继续按原归属处理。2026-11-11 简化：明确领取后显示已领取状态，点击「进入项目」直接打开项目首页；首次录音与后续录音统一从首页发起，不设置独立首讲页面。

2026-11-11 礼物列表改为「我送出的／我收到的／我参与的」，自己送自己的书同时出现在送出和收到两类，打开同一本书。普通受邀家人填写「你是主讲人的谁」，按主讲人视角记录称呼；购买者首次提问缺少该关系时补填，不从购买时的赠礼关系反推。普通受邀家人属于参与者，不作为指定收礼人。完整新需求见[红色 note 整理](../../designs/timenook-modern-2026-11-10/project/REQUIREMENTS-2026-11-11.md)，其中产品规则已确认且原画布已同步，业务实现尚待更新。

现有画布页面及状态见[送礼流程](../../designs/timenook-modern-2026-11-10/project/BUSINESS-FLOW.md#送礼)。
