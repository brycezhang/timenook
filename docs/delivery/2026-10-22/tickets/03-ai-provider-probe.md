# T03 · 验证豆包文件转写与 DeepSeek 生成质量

状态：draft-review（待确认拆分，尚未发布到 GitHub）
阶段：S0

## 交付结果

从同一封存样本取得真实文件转录、一条可选追问和带来源的整理稿，记录时延、费用与失败恢复结果。

## 验收条件

- [ ] 固定豆包资源/API/配置版本和稳定请求 UUID，验证公网限时取源、STS 剩余有效期、提交未知后查原请求及业务状态码。
- [ ] 区分 HTTP 受理、处理中、无有效语音和最终成功；转录原文独立保留，空白转录不生成故事。
- [ ] DeepSeek 输出追问和稿件结构经过校验；人工核对口音、模糊年代、矛盾、拒答及不适用经历，不自动跨供应商回退。
- [ ] 分别记录停录到转录、转录到追问、提交整理到出稿及失败率/用量；不能以主动失败凑时延目标。
