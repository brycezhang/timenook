# T03 · 验证豆包文件转写与 DeepSeek 生成质量

GitHub：[#4](https://github.com/brycezhang/timenook/issues/4) · 状态以 GitHub 为准。
阶段：S0

## 交付结果

从同一封存样本取得真实文件转录、一条可选追问和带来源的整理稿，记录时延、费用与失败恢复结果。

## 验收条件

- [ ] 固定豆包资源/API/配置版本和稳定请求 UUID，验证公网限时取源、STS 剩余有效期、提交未知后查原请求及业务状态码。
- [ ] 区分 HTTP 受理、处理中、无有效语音和最终成功；转录原文独立保留，空白转录不生成故事。
- [ ] DeepSeek 输出追问和稿件结构经过校验；人工核对口音、模糊年代、矛盾、拒答及不适用经历，不自动跨供应商回退。
- [ ] 记录停录/封存/转录/追问/整理的关联事件及分段耗时、失败率/用量，供 T15/T18 复用；不以失败凑时延。合成用例只验计时逻辑，真实口音、质量、成功率和费用留证。

## 实现边界

固定本次评测的供应商配置、提示词和输出契约；T15/T17/T18 复用 adapter、状态映射、校验与计时口径，生产调度统一归 T15，探针不再扩成第二套产品流程。
