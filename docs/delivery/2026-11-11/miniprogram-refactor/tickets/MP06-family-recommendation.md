# MP06 · 家人提问、混合推荐与故事书首页

状态：ready-for-agent；GitHub [#173](https://github.com/brycezhang/timenook/issues/173)，父规格 [#166](https://github.com/brycezhang/timenook/issues/166)。父规格：[小程序全量重构](../spec.md)。

## 交付结果

家人文字提问，主讲人从首页优先看到家人问题并语音回答；问题在故事完成后显示回答结果。

对应差异：F07、F08、F10、F11。主责画板：`HomeEmpty`、`HomeActive`、`FamilyQuestions`、`FamilyQuestionsEmpty`、`FamilyQuestionNew`、`FamilyQuestionDetail`、`FamilyQuestionAnswered`。详见[画板对照表](../DESIGN-MAP.md)。

## 验收条件

- [ ] 家人只输入文字，章节可选；从章内带入但能取消，购买者缺关系时首次提问补填，不反推赠礼关系。
- [ ] 保存原作者、昵称与主讲人视角关系；首页、列表、详情及讲述来源一致，他人编辑不替换作者。
- [ ] 建立问题到完成故事的关联；创建采访或实际提问不等于已回答。支持待答、稍后、跳过、恢复、编辑和删除，删除题不删故事。
- [ ] 首次优先家人，两类充足时约 2:1 穿插、类内随机、本轮不重复；一类不足补足。轮次耗尽可重开，稍后题仍在本次进入周期排除，下次进入才恢复推荐。
- [ ] 问题与开始讲述同卡滚动；故事数、照片数、书名封面整块各是唯一对应入口，零数量仍可进入空态。
- [ ] 首页真实统计、原声整数分钟、家人问题数量和跨项目推荐状态正确，已回答卡片进入关联故事。
- [ ] 本票全部主责画板完成设计与原生 UI、交互对照，记录 390px/320px、真实入口、截图与差异处理；不留死入口或用样例数据冒充业务。
- [ ] 实现、相关检查、原生验证及外部待验分别记录，改动与测试只覆盖本票实际边界。

## 数据与契约边界

本票按新方案直接修改相关前后端、共享契约和数据库。开发数据可破坏性重建，不做旧模型兼容、双写或旧接口别名。影响现有网页/后台消费者时同步适配，不扩展视觉范围。

## 测试决策

API 题→采访→完成故事链路、作者权限和推荐周期行为测试；原生文字提问→不选章→首页换题→语音回答→已回答故事路径。

复用现有测试入口，优先验证公开行为；数据库约束使用真实 PostgreSQL/Redis。外部待验不视为功能缺失，已实现能力与未验环境分别说明。
