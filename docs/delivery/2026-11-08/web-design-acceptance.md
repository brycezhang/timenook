- 新设计稿与线上页面均本轮重新打开并截图；采用用户允许的 Playwright。主查 Chromium 320×568、390×844，补查公开页 768/1440px 与桌面工作台；WebKit 320×568 复查真实服务器的成员首页、书稿和录音入口。
- 私有页面使用已有、无手机号/微信身份的虚构内容项目与新建临时空账号，内容来自真实 HTTP/API/数据库。运维临时会话不算短信登录证据。本轮没有操作用户两个真实项目，没有新短信、订单、付款或印刷提交。
- 网页类型检查、正式构建与发行包检查通过。`tests/web-mvp/` 的 21 个场景分段回归覆盖登录/同号账号、成员与邀请、故事/照片、录音/上传/整理、书稿/PDF/原声、支付回跳交付、地址/印刷与失权清理；外部短信/支付/AI 和音源采用本地隔离替身，数据库/Redis、业务 HTTP 和浏览器为真实运行。
- 先运行完整套件，再按实际失败适配新入口并定向复测；没有把首次失败或旧流程测试当作通过。WebKit 曾偶发停在音频初始化；现场服务端授权已成功，合成音源未接管。测试夹具现固定同一个 `MediaDevices` 实例，并在录音中确认仍为合成输入；最后双引擎真实录制/上传及布局回归 4/4 通过。该修正仅在测试中，不改变正式录音或服务端授权实现。
- 截图与测量位于 Git 忽略的 `output/playwright/web-design-fixes-20261108/`，本机 `gallery.md` 提供设计稿/最终页面配对。录制/暂停截图为本地合成音源，线上录音图为准备状态。截图已实际查看；全页图中固定底栏的位置属于取图视口，遮挡结论使用视口图与元素坐标。
