# T20 · 冻结书稿快照并生成完整可核对 PDF

GitHub：[#21](https://github.com/brycezhang/timenook/issues/21) · 状态以 GitHub 为准。
阶段：S3

## 交付结果

用户按实际目录生成包含全文、照片及原声入口的完整书稿，总览与 PDF 显示同一版本。

## 验收条件

- [ ] 一次冻结大纲、实际目录/顺序、获准入书故事版本、素材、封面、规格和原声清单；先分配稳定二维码入口再渲染。
- [ ] 渲染器只读快照，独立进程/资源；固定字体、Chromium 和模板，目录分页收敛失败则明确失败。
- [ ] 验证文字完整、图片、二维码、真实页数和生产规格；最终文件保存 hash/渲染版本，必要印前转换后重新冻结。
- [ ] 小程序书封/目录/节选/页数来自同一快照，鉴权下载完整 PDF；改内容/实际目录使待生产书稿失效，空章节不填假文。
- [ ] 按 D08 核验的适用规则，将 AI 整理与人工校对来源标识写入制作说明/PDF 并随快照冻结；逐页/文本检查标识、确认稿与 PDF hash 一致，真实原声及其入口不误标为合成音频，标识变更后重新生成并确认受影响版本。

## 实现边界

复用 T04 固定渲染器和 T15 任务机制；增加确定书稿快照、标识及鉴权交付，不另造分页引擎。按一套 D01 规格输出，生产增量与受影响样本单独验证。
