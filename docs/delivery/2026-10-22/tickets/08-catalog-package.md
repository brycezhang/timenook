# T08 · 发布动态赠礼关系与不可变套餐

2026-10-29 当前目标按 [ADR 0017](../../../adr/0017-lifetime-service-and-retention.md) 更新；长期规则及工程调整见 [#105](https://github.com/brycezhang/timenook/issues/105)；正式环境、设备及供应商验收仍按原责任票留证。

GitHub：[#9](https://github.com/brycezhang/timenook/issues/9) · 状态以 GitHub 为准。
阶段：S1

## 交付结果

运营发布关系目录和套餐后，小程序展示相同的价格、称呼及服务条款；配置不完整时明确不可购买。

## 验收条件

- [ ] 关系 code 稳定，可新增、排序、停用；支持项目自定义称呼，不以父母枚举限制，也不自动添加全局类型。
- [ ] 套餐发布生成不可变版本，99900 分、币种及 D01–D08 必需参数完整才可售；缺失参数可保存草稿但不能发布。
- [ ] 小程序读取目录和套餐，展示一个项目一本实体书、配送、长期服务及退款说明，所有关系使用同一套餐。
- [ ] 运营修改不回写已发布版本；冻结首批 D10 关系文案与支持边界；关系不推断经历、性别或权限。
- [ ] 套餐按 ADR 0017 明确制作、回听、导出申请和下载长期有效，必要资料长期保留；用户端不展示服务倒计时，后台不提供期限动态配置、暂停计时或到期操作。套餐快照保留真实价格、权益及售后规则，冻结合成预览不能成为正式可售版本。

## 实现边界

保留动态关系管理；首版只发布一套已选政策的套餐，缺参草稿和历史不可变版本仍保留。采用现有导入/校验和发布能力，不建设政策组合编辑器或多套餐选择。
