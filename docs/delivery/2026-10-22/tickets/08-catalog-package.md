## 交付结果

## 验收条件

- [ ] 关系 code 稳定，可新增、排序、停用；支持项目自定义称呼，不以父母枚举限制，也不自动添加全局类型。
- [ ] 套餐发布生成不可变版本，99900 分、币种及 D01–D08 必需参数完整才可售；缺失参数可保存草稿但不能发布。
- [ ] 小程序读取目录和套餐，展示一个项目一本实体书、配送/期限/退款说明，所有关系使用同一套餐。
- [ ] 运营修改不回写已发布版本；冻结首批 D10 关系文案与支持边界；关系不推断经历、性别或权限。
