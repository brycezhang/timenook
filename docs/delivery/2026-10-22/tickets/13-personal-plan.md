# T13 · 编辑个人大纲、问题和拒答偏好

GitHub：[#14](https://github.com/brycezhang/timenook/issues/14) · 状态以 GitHub 为准。
阶段：S2

## 交付结果

双方可调整个人计划，讲述者随时跳过、拒答或禁问；从默认问题即可开始，无需先填完设置。

## 验收条件

- [ ] 复制模板为独立计划版本，支持章节/问题增删改排序，保留个人内容和已回答关联；MVP 不提供换模板。
- [ ] 用 expectedVersion 原子更新，双角色并发返回 409，禁止静默覆盖。
- [ ] 稍后、跳过、不适用和禁问分别保存；发起人编辑不能复位本人偏好，重新启用走本人核验。
- [ ] 历史实际提问保持原样；未来问题改写不重转写/不撤销故事确认，实际目录变更触发受影响书稿失效。

## 实现边界

复用 T09 事务内计划初始化与版本模块，增加授权编辑；已有初始化/升级证据直接引用，新增验证双角色冲突和偏好。保持单套模板，可清空或自拟个人计划。
