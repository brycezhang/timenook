# 产品网页 Vue 重设计

用户确认范围为 `apps/web` 的项目、故事、录音、书稿与我的；现代简洁风格参考 shadcn，移动设备优先，设计 token 沿用小程序。营销官网不在本轮范围。

已落地的设计见 [原型与说明](../../../designs/timenook-web-2026-11-07/README.md)，使用 Vue 3 SFC，配套 Baoyu Design System 文件及可编辑 token。新增设计原型未替换 `apps/web`，也未修改营销官网、小程序、后端、CI 或生产部署。

## 工程与浏览器结果

Vue 类型检查、独立打包和设计系统结构检查通过。Chromium 已覆盖手机/平板/桌面布局，故事阅读编辑与入书切换、项目与昵称、弹窗、示例网页书稿阅读，以及浏览器合成麦克风的开始/暂停/继续/结束/回听/重新录制。320×568 录音操作保持首屏可用。

## 真实业务边界

内容与项目为示例数据，录音只在当前页回听，不上传。书稿仅作示例网页阅读，不生成生产 PDF；不生成有效邀请、真实订单、付款或印刷任务。真实接口整合、当前业务流程完整落地及真机 Safari 验收尚未实施。设计 token 与流程方向按本记录执行，真实业务状态继续以各应用运行证据为准。

## 未登录状态补全

补齐了未登录首页、公开样书、登录弹窗、未登录“我的”、已登录暂无项目及故事/书稿/项目空态。默认进入未登录首页，顶部可切换三种账号场景及登录演示结果。未登录点击私有入口先登录；取消留在原页，成功回到原入口，登录本身不创建项目或发起支付。退出后清空本页示例项目与媒体引用。

登录覆盖默认未勾选条款、阅读返回、提交中、取消、失败后重试及有项目/无项目结果。浏览器验证覆盖 320–1440px、新购前登录、公开样书、私有深链拦截、新建首个示例项目与已有项目入口。类型检查及构建通过。网页登录渠道未在本原型中新增决定，真实认证与业务 API 仍未接入。
