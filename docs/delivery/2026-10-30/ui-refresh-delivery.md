# 双端 UI 工程交付与发布入口

对应 [#120](https://github.com/brycezhang/timenook/issues/120)、子票 #121–#124 与 [PR #126](https://github.com/brycezhang/timenook/pull/126)。已定范围见 [实施规格](ui-refresh-spec.md) 和 [已确认原型](../../frontend/ui-review-2026-10-30.md)。

## 工程结果

- 统一纸色、宋体阅读和橄榄绿操作层级；网页桌面为侧导航和宽阅读区，移动网页和原生小程序保持底部导航。
- 项目页突出待确认、最近讲述及本机恢复，历史折叠，故障仍有可见入口。选题主次按钮分行；换题消费服务端按个人计划和禁问等规则过滤的真实问题，提交当前 key。
- 保存只显示真实上传、封存和任务状态。原件未提交或任一片段转写未成功时，不能提前整理；未知封存保留原片段重查。测试存储不称云端，没有百分比、预计时间或模拟完成。
- 用途页只有简短介绍、折叠详情及「确认并开始」，实际点击原子记录既有采集、AI、共享三项，打开页面不授权。进入新草稿准备，不自动开麦；旧素材从恢复入口继续。
- 故事只用「确认」，无需复选框、手写说明或独立入书用途说明；仍保留确定版本、本人/有效协助、真实点击证据及明确调整决定。同一讲述者跨故事版本和账号换绑保留旧拒绝，新的正向确认继续校验当前绑定。
- 成书、PDF、邀请、大纲、我的及帮助沿用真实数据和接口。服务页可查询既有工单、进入用途管理、导出及删除进度，没有新增即时客服接口。网站明确内测和模拟支付。
