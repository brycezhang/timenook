# WV08 网页制作与物流

独立 Vue 页面 `/app/projects/:projectId/production` 已接入现有首本与履约公开接口，复用安全 Cookie、CSRF 和成员会话校验。网页书稿页可链接该入口；固定书稿使用 WV06 的 `?version=` 路由。

任一当前项目成员可填写服务端套餐支持的地区、带版本保存地址，并按当前就绪的书稿版本、快照、PDF 与地址哈希直接提交。未保存地址、错版、权益不足或内测 `physicalProduction:false` 均不能提交。提交响应未知时先查询结果，同一输入复用幂等键；确认取消后沿原生产单保存新地址并重新提交，保留历史制作记录。未增加本人或双方确认、核对勾选或计时完成状态。

页面区分待安排、交接待核实、正在印制、已完成印制、已发货和已送达；展示实际承运公司、单号及登记时间。取消待核实与确定取消按实际履约记录显示。当前用户端没有取消 API，变更制作安排通过条款中的客服渠道处理，网页不调用管理接口。

本地定向验证：Vue 类型检查与正式构建通过；`tests/web-mvp/production.test.mjs` 两项 Chromium 测试使用真实 HTTP、独立 PostgreSQL schema、Redis、Worker、HTTPS 构建产物，覆盖非买方成员提交、提交响应丢失后查询、取消重提、独立印制/物流/送达事实、地址冲突保留草稿、书稿变化后阻止错版提交、失败重读及无实体权益。320/390/1440 宽度检查及手机/桌面截图通过，无页面异常。

测试中的印厂、印制、物流与送达均是管理公开接口登记的合成事实，没有联系印厂、发货或操作资金。真实支付权益、印厂、物流、目标用户与真机验收另行记录。未推送、部署或发布 GitHub 票据。
