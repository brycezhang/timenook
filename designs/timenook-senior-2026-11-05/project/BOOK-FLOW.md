# 书籍预览与印刷：简化流程

2026-11-05 最新决定，以 [BUSINESS-FLOW.md](BUSINESS-FLOW.md) 为准。当前原型已更新，原生小程序和后端尚未改动。

## 入口与角色

购买者和接受邀请的成员使用相同的项目功能。首页 → 我的书 → 预览或印刷；不再分讲述者/发起人，不要求本人确认或同机协助。

预览用于看完整书稿，可以随时返回或直接去印刷，不要求每页依次点过，不产生独立的确认记录页面。

## 章节与正文

目录仅显示序号和名称。名称区点击直接显示本章各故事的正文输入框；右侧独立把手用于按住拖动排序，不再放进入箭头或上移/下移按钮。可以添加章节。

保存章节正文同步对应故事的内容版本；章节支持选择故事和调整故事顺序。移除章节不删除项目内原故事。新整理故事默认入书，成员可选择暂不入书。采访话题仍和实际成书目录分开。

「本章故事」分为“已加入本章”和“可添加的故事”，两区均显示篇数，同一故事不重复出现。已加入区用浅绿卡片与序号标识，通过右侧把手拖动排序或点击移出本章；仅一篇时隐藏拖动把手。可添加区用白色卡片及“加入本章”按钮；其他章节中的故事注明当前章节并显示“移到本章”。加入、移出和移动后，两区内容与数量立即更新。移出只改变章节归属，不删除故事。拖动与进入正文/移出按钮分区；只有把手接管拖动，内容区仍可正常滚动。

书封可修改书名、称呼和封面照片。有图片时直接显示；点击“更换封面照片”进入独立选择页，从可入书故事的已有照片中选取，当前照片标记为已选。选中即返回书封预览，最后保存书封。没有照片时显示空状态，也可选择文字封面；不新增直接上传或模板商城。名称同时用于当前项目和列表。

当前 main 已有「本章故事」选择/移出、跨章移动和章内排序实现，因此保留这个二级页。一个故事只能归到一个章节，移到新章时会从原章移除。详见 [核对记录](BOOK-COVER-AND-CHAPTER-CHECK.md)。

内容、目录或书封修改后重新生成书稿；不再触发本人或双方确认。提交制作时冻结该书稿版本和地址，后续修改不改写已提交文件。

## 直接印刷

1. 在项目中打开我的书，点击“印刷这本书”。
2. 无地址时填写并保存；已有地址直接进入印刷页，也可修改。
3. 显示本次书稿、地址与首本 ¥0，点击“提交印刷并寄送”。
4. 显示制作与物流进度。

没有用途选择、本人确认、双方确认、勾选、手写核对结果和独立制作授权页。使用条款在登录/接受邀请时统一接受，后续不再重复。

仍保留：就绪书稿、真实首本权益、有效地址、结果未知时查询原提交、防止重复制作。书稿未就绪先生成；实际已取消的制作可修订后再提交。首本 1 本不重复收费。

## 状态与样例

设计包含生成中/失败/内容更新、已提交/制作中/印好/发货/交付/取消/待核实。状态反映实际记录，刷新不能自行变成已发货或退款成功。

原型用示例内容动态组成预览页，实际生产 PDF 的排版与页数仍以生成结果为准。未加入加印收费、封面模板商城、固定装帧/页数、固定承运商或发货时限。

图片、文本、地址、地区与运单为设计样例。所有交互均为本地模拟，不创建真实生产单、通知印厂或发送邀请。
