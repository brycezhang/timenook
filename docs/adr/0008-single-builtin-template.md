# MVP 后端内置一套固定大纲模板

根据用户 2026-10-22 的范围调整，MVP 跳过运营创建、编辑及发布大纲模板。后端以代码维护一套固定、中性的大纲与问题，不提供多模板选择、推荐或切换。

创建项目时把默认模板的确定版本复制为独立个人计划。模板标识、版本和内容 hash 保持稳定；以后通过代码发布新版本，不覆盖既有项目。发起人与讲述者仍可按 ADR 0005 编辑个人章节及问题；实际提问快照、拒答/禁问偏好、故事与书稿确认规则不变。

这项决定替代 ADR 0005、PRD V1.0 和架构 V1.0 中关于多套模板与运营模板发布的 MVP 范围，不改变个人计划的版本约束。D09 内容审校、原创或授权来源与质量试用仍需完成。

当默认模板无法覆盖已验证的用户需求，或更新频率需要非研发人员持续维护时，再评估运营模板管理；本轮不预建管理页面和接口。
