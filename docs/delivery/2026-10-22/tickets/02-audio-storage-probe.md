# T02 · 验证真机录音、私有封存与鉴权回听

GitHub：[#3](https://github.com/brycezhang/timenook/issues/3) · 状态以 GitHub 为准。
阶段：S0

## 交付结果

在受控测试入口用已授权样本完成录音、本地保存、私有 OSS 封存及回听，形成可复现的双端证据。

## 验收条件

- [ ] iOS/Android 记录设备、微信版本、音频格式、时长与 hash，覆盖麦克风拒绝、来电、后台、断网及强杀；只承诺实际已保存片段。
- [ ] 验证精确暂存 key 的短时上传权限、真实格式/解码检查、最终对象复制复验；HTTP 上传成功不显示为云端封存成功。
- [ ] 测试身份隔离于产品账号；鉴权下载到临时文件后本地播放，检查 Range、过期权限、缓存清理；桶与原声不公开。
- [ ] 永久凭据不进入客户端或证据；失败记录可定位到设备保存、上传或封存阶段，明确采用参数和剩余风险。
