# 网页短信验证码与小程序手机号统一产品账号

用户决定正式网页版使用 Vue，按 2026-11-07 新设计实现；网页通过手机号验证码登录，与小程序以同一已验证手机号识别同一个产品账号。小程序继续验证微信登录身份与微信手机号授权。两端共用 TimeNook 的用户、项目成员、昵称和权益，网页 Cookie 会话与小程序 Bearer 会话保持各自的传输与撤销边界。公开入口、短信登录及同号账号解析已部署开发环境；真实验证码登录与真机同号仍待实际验收，运行结果见[阶段记录](../delivery/2026-11-08/web-mvp-entry.md)。

手机号须在服务端规范化并建立唯一归属；短信验证码或微信服务端手机号证明通过后，使用同一账号解析逻辑。网页先注册、小程序先注册及两端同时首次登录均不得产生两个产品账号。微信身份关联到该账号；不把手机号字符串、浏览器输入或收货手机号直接当成身份凭据。以手机号联通只发生在 TimeNook 的产品账号域，不合并 deed、梧桐或管理后台账号。

同一个已验证手机号不再要求另做二维码配对或双端手动关联。既有微信身份与其他账号/手机号的归属冲突不得静默搬移项目和权益；首版不提供自助账号合并或手机号换绑，由客服核验处理。开发阶段直接更新模型和必要夹具，不建设历史开发账号迁移、旧登录链接兼容或跨项目用户迁移；实际数据处置仍需单独确认，规划不等于授权删除资料。

2026-11-08 用户确认邀请的跨端路径：网页生成的邀请链接在网页完成手机号验证码登录并接受邀请，即使从微信聊天打开也不强制跳转小程序；小程序分享在小程序完成手机号授权并接受邀请。已登录时复用当前有效会话，未登录时完成登录后回到原邀请；接受有效邀请后取得对应项目成员资格，收到链接或仅登录不自动加入。不另设微信身份绑定或跨端配对要求，两端以同一产品账号访问同一项目。此路径已在 Vue 页面及真实成员接口本地实现，部署与真实双端结果另记。

正式 Vue 应用独立实现网页视图，复用现有业务接口、版本规则、可靠上传和浏览器媒体能力，停止把小程序 WXML/WXSS 页面运行器作为产品网页渲染方式。新设计中的「状态预览」、账号场景切换、`state` 查询参数、登录结果模拟、示例个人项目和模拟支付均不进入正式源码或发布包。未登录、空项目、加载、失败等真实状态必须来自会话、接口和任务结果；公开样书仍是明确标注的公共示例。

网页首版支付已另行确定为 TimeNook 后端调用现有 payment-service 的支付宝 Page/WAP，暂不接系统退款、不修改共享服务；本决定不替代支付准入、资金结果或商户后台配置。见[网页开发计划](../delivery/2026-11-07/web-vue-development-plan.md)。
