# T26 · 执行资料删除及备份恢复防复活

GitHub：[#27](https://github.com/brycezhang/timenook/issues/27) · 状态以 GitHub 为准。
阶段：S4

## 交付结果

资料删除请求按范围清理活动内容、历史对象、导出与供应商副本，并如实展示尚待到期或确认的部分。

## 验收条件

- [ ] 删除清单覆盖原声/衍生图/转录/稿件/PDF/ZIP/临时目录/对象历史版本/任务输出；财务记录与内容删除分开。
- [ ] 墓碑和独立撤回/删除台账阻止迟到结果、恢复扫描和旧备份重新开放资料。
- [ ] 真实验证活动对象/数据库内容/缓存清理；各层副本分别报告处理期限和状态，备份轮换及供应商副本不可核实部分保留待处理。
- [ ] 隔离恢复演练先应用删除/撤回台账再开放访问，用户可见在线访问停止、活动删除、备份待到期、外部待确认的区别。
- [ ] 除用户核验删除请求外，接收 D03 保留期届满事件，按文件类别/副本层级的冻结期限进入同一删除清单；覆盖到期前/恰好到期/到期后、重复扫描、重启及停机补扫。
- [ ] 制作期限到期/退款不替代保留期届满，资料到期沿同一删除台账执行；恢复前应用台账的本地机制证据由本票提供，正式恢复归 T29。

## 实现边界

复用 T24 撤回与 T15 任务机制；活动资料与到期补扫由系统执行，备份轮换和供应商回执按冻结规则核验。人工维护外部待办，不能人工确认一个总 deleted 状态替代逐层证据。
