# T10 · 核验付款并唯一激活人生项目和首本权益

2026-10-29 当前目标按 [ADR 0017](../../../adr/0017-lifetime-service-and-retention.md) 更新；长期规则及工程调整见 [#105](https://github.com/brycezhang/timenook/issues/105)；正式环境、设备及供应商验收仍按原责任票留证。

GitHub：[#11](https://github.com/brycezhang/timenook/issues/11) · 状态以 GitHub 为准。
阶段：S1

## 交付结果

发起人付款或退出后查询订单，都恢复同一个人生项目、讲述者、默认计划和首本权益。

## 验收条件

- [ ] 创建订单冻结价格、币种、套餐/关系/模板快照及稳定商户单号；下单结果未知先查询原单。
- [ ] 通知验签、解密、核对应用/商户/订单/金额/币种/状态后持久化 Inbox 再应答；通知与主动查单走同一入账用例。
- [ ] 真实 PostgreSQL 事务一次激活支付、默认项目/subject、计划及权益；同键重放、异载荷 409、不同键并发和漏通知恢复均验证。
- [ ] 小程序付款成功/取消/超时均查询服务端，失败不发权益；关单竞态保留真实支付事实；未填姓名或书名也可继续。
- [ ] 按 ADR 0017 将已核验付款项目的制作、回听、导出与必要资料保留统一为长期有效；付款、本人参与及交付继续记录真实幂等事实，不再启动服务倒计时或未开始失权流程。移除暂停/恢复计时、暂停上限与到期审核。
- [ ] 为 T14/T21/T22/T23/T25/T26 提供一致的长期服务语义；时间推进、并发、重放、重启不阻止已获授权的制作/回听/下载，也不按服务时间自动清理资料。若持久字段必须有日期，只写固定 2099-12-31，占位不作为业务到期判断；退款及主动撤回/删除仍按各自规则执行。
- [ ] 普通商户支付通知内部 `/v1/webhooks/wechat-pay/payments`、公网 `https://timenookapi.threeminreading.com/api/v1/webhooks/wechat-pay/payments`；生成/核验回调地址不漏或重复前缀，真实商户通知与查单证据分别记录。

## 实现边界

执行当前长期服务方案及固定价格/权益政策，删除旧开发期限分支，不建设期限配置或续期能力。商业冻结、退款权益后果、本人授权、权限与审计继续由原用例检查。
