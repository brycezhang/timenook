## 本票实现

五分钟单次关联挑战绑定原网页会话与 User；微信 code 服务端证明、独立核对码、双方明确确认及身份唯一锁；只将经验证身份附加到原 User，不建重复账号、不合并项目。两端有明确入口和未配置提示，关联与本人用途授权分开。完整协议及接口见[运行说明](../../development-wechat-link.md)。

新增迁移只增加 `wechat_links` 挑战表，不改变长期服务、付款、项目或授权模型。正式微信凭据继续 unset。本轮没有部署或真实微信调用。
