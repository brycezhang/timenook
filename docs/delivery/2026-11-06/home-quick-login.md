# 首页购买先快捷登录

2026-11-06 用户报告：未登录时点击首页 999 元购买，先进入「新购一本书」再登录；要求先复用弹出快捷登录，成功后进入「新购一本书」，并指出所见登录逻辑未更新。

## 修复

- 使用实际首页页面回归复现：点击购买错误地立即导航 `/pages/new-book/index`，未出现登录弹窗；修改前测试已失败。
- 新增共用 `components/quick-login`，首页、「我的」和原独立登录承载页复用相同的协议、手机号授权及会话逻辑。无需先导航至登录页，也不在首页另造第二套登录接口。
- 未登录点击 999 元，在首页显示底部快捷登录；默认协议未勾选，明确选择后通过 `getPhoneNumber|agreePrivacyAuthorization` 登录。请求包含独立的微信/手机号 code 和当前条款版本，沿用已部署的手机号服务端和系统默认昵称。
- 登录成功才进入「新购一本书」，没有创建订单或支付。已登录直接进入。取消、拒绝授权或网络失败均留在原页面；失败可重试，取消后普通登录不会残留购买跳转意图。
- 「我的」普通登录成功后原地显示昵称；「我的」未登录新购也走同一弹窗。显式邀请、原声和开发关联等承载页继续保持返回上下文，通过同一组件完成真实登录。
