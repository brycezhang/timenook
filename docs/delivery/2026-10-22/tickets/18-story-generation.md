# T18 · 从完整转录清单整理可核对故事

状态：draft-review（待确认拆分，尚未发布到 GitHub）
阶段：S2

## 交付结果

用户提交整理后取得带来源、待本人确认的第一人称故事；原声和原始转录保持独立。

## 验收条件

- [ ] 提交时冻结全部已选封存片段/转录依赖及 baseVersion，不漏掉仍在转写的后半段；空白无效语音不生成故事。
- [ ] 校验标题、段落/sourceRefs、主题和 reviewItems，拒绝无来源引用、无效 JSON 与空段落，保留模糊事实与矛盾核对项。
- [ ] 补录/改稿/撤回期间迟到结果标为 obsolete，不覆盖新稿；失败从原素材恢复，明确用户重生成与系统重试额度。
- [ ] 小程序显示实际任务阶段、AI 整理标识、全文和待核对项；已保存原声可回听，退出返回恢复同一任务。

## 外部条件与完成边界

真实生成质量由授权样本人工对照验证；结构检查不等同事实准确。

关闭前记录提交/PR、执行命令及结果、对应证据。只有本地适配器通过时写明“模拟已通过，真实验收待完成”，保持本票未关闭。凭据通过受限的 Git 忽略环境文件或平台密钥管理提供，不附在 issue 或日志中。
