## 已实现

- `POST /v1/projects/:id/interviews` 建立稳定采访和实际提问，`GET` 列表/单项恢复当前授权内容。计划题由服务器确定版本读取；照片、自由讲述、自拟及当场改写来源进入同一个 `ProjectPlans.captureActualQuestion` owner。文本、目的、计划版本及原问题来源不可变，`answerRef` 只关联一次稳定采访，多段录音归同采访。默认题跳过本人稍后/跳过/不适用及禁问主题；空白计划仍可自由/照片/自拟起讲。
- 新增 `Participation.withCollectionAccess`：真实 session SHARE → Project → Subject 锁序，本人当前采集许可和制作期限，协助复用最新、当前有效 `authorizeAssisted(collection)`，在写入事务内复核。没有把 buyer 伪装成 narrator，没有强加 sharing/AI。旧采访在撤回重授、换绑等 binding/epoch 变化后，重放 start、新建片段、开启麦克风均不自动恢复旧上下文；合法当前读取历史与新采集分开。
- `POST .../interviews/:interviewId/recording-start` 在开麦前复核当前采集权限；页面缓存不是授权。collection-only 协助使用最小 `POST .../interviews/context`、`.../:interviewId/resume` 与 `.../clips/:clipId/status`，只恢复同操作人当前采访/上传所需状态。私人列表、历史及原声仍需当前 sharing；采集不授予 AI。
- `POST .../interviews/:interviewId/clips` 固定 `clientClipId`、采访/实际问题、预期 bytes/hash、主体/操作人、binding/epoch 与存储身份。真实 PG 唯一键和复合 FK 拒绝跨项目及同项目错采访关联。HTTP 幂等键异命令、同 client ID 异载荷冲突，不同 HTTP 键并发仍复用一个意图。订单冻结 D04 秒数与实际毫秒精确比较；按单段上限、技术上限和当前剩余的最小值预留，成功结算实际时长，release 释放预留，不重复消耗、不引入商业取整。
- `.../upload` 消费既有 blob `uploadForm`；本地模拟表单精确 key/长度、120 秒 capability 且绑定当前 API session，上传仍须当前采集权限。OSS 装配直接复用 `OssProbeObjects`，没有重写签名或 STS。客户端只向本 API 的本地上传附 bearer，外部 OSS 不携带 API bearer，目的地严格验证；切存储后旧意图不可重标。
- 共用 `sealAudio`：T02 完整 MP3 类型/单音轨/16kHz/mono、完整解码、实际时长、2MiB/300s 技术限制、hash 与最终对象复验。先把已验证字节放入服务器独占临时快照，再 copy 到稳定 final，仅清理自己的临时快照；避免可变 staging 在并发完成时覆盖已成功资产。I/O 在业务终态事务外，之后重新查当前 session/主体/用途/绑定/epoch/协助到期/制作期限。
- `POST .../seal` 在一个 PG 事务写 `RecordingAsset`、`RecordingClip`、用量终态与唯一 `SealedInput`。复制成功而 DB 失败仍 pending，同意图重试可恢复，不盲删 final，不重复扣额。资产保存实际 provider、store、scope、key、hash、bytes、MIME 与时长；private/no-store/Range 共用 T02 响应处理。原声读取在 I/O 后再次复核当前共享权限及适用 D03，已 sealed 的读取/完成状态不由 `canRecord` 统一拦截。
- `LocalAudioRecorder` 是探针与产品共用的一份设备/本机文件生命周期，继续使用共同 recorder lease。实际 interview 页面区分 requesting、recording、saving、local、uploading、sealing、sealed；saveFile、hash/size 和 manifest 都成功才报本机保存。清单失败重试复用已保存路径。manifest 按 deployment/AppID/稳定账号/project/interview 分区；session 和页面 generation 只作迟到 fence，同账号重新登录可恢复。账号变化、离页和 401/403 清空私人视图/自拟草稿，旧回调保留原归属，不删除唯一 pending 文件；后台/来电 stop，返回不开麦。多个本机采访 ID 索引避免另起问题后丢失旧 pending 入口。
- live welcome → project 主页 → interview、同机协助 → interview 均实际接通；录音、查询、重试、恢复均走产品 HTTP。默认内置问题、自由、照片和自拟来源保留。模拟封存明确标记，未声称转写开始；没有队列、Worker、ASR、StoryVersion 或照片生产模块。
