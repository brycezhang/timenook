# 渠道礼物按手机号关联，第三方销售使用受限后台账号

用户在第三方微信小店付款并提交购买者手机号，之后进入时光故事小程序选择送给谁。第三方运营销售需要直接录入购买事实。用户确认由后台人工录入，手机号关联产品账号，确认书名和赠礼关系后创建故事书。

## 决定

- 后台支持两种身份。通过现有飞书白名单登录的人员为超级管理员，可管理订单、用户、生产单及第三方账号。超级管理员可生成、撤销或删除第三方账号，并在弹窗查看密码。第三方登录后只有「录入订单」业务入口，页面与服务端均执行该权限。
- 录入订单只要求购买者手机号。界面无店铺字段；原订单号、实付金额、付款时间等补充信息均可留空。服务端自动记录内部编号、录入账号、录入时间及现有固定套餐快照。一条录入记录对应一份套餐。
- 已有同号产品账号时立即关联；未注册时先保存待关联记录，用户以同一已验证手机号注册后自动关联。填写的购买者手机号决定礼物归属。购买者手机号和收礼手机号分别记录。
- 购买者在「我的礼物 → 我送出的」查看待送礼物，确认赠礼关系与书名后，原记录单次创建故事书和首本制作权益。送给自己直接进入故事书，送给他人继续指定收礼手机号并生成礼物卡。
- 创建故事书前，超级管理员可处理全部渠道记录，第三方可处理本人录入记录，均可更正购买者手机号或因录入错误作废，保留原因、操作人和时间。创建后锁定购买者归属。第三方账号的撤销终止其后台访问，已录入的有效礼物继续归属于购买者。
- 未关联账号及未送出的礼物长期有效。新增礼物按账号提醒一次，多份合并提示；查看或稍后后继续通过「我的」查看待送出数量。从礼物卡或家人邀请进入时先完成原操作。
- 渠道退款登记、退款权益联动及小程序查漏工单留待后续需求。用户经原购买渠道联系人工核查。录入错误作废保留在本轮范围。

## 实施取舍

手机号码必填且允许重复购买，所以手机号无法作为订单去重依据。每次明确的新录入产生一份礼物，同一次提交重试或重复点击复用原记录。可选的外部订单号作为参考信息保存；内部编号和录入账号用于追溯。

第三方在唯一「录入订单」入口提交订单、查看本人录入记录，并更正／作废本人尚未建书的记录。超级管理员可处理全部记录及查看账号匹配信息。服务端按录入账号校验第三方可访问的记录。第三方凭据由超级管理员生成并交付。登录使用带盐的 scrypt 哈希，新生成或重置的密码另用服务端密钥加密，供超级管理员在经同源和 CSRF 校验的弹窗中查看。旧账号原密码只有哈希，重置后可查看新密码。重置使旧密码和旧会话失效。撤销立即禁用账号。删除同时清除凭据、移出账号列表并保留历史操作人、渠道记录和买方礼物。查看、重置及删除记录审计，审计只记录操作事实。

可选金额与付款时间缺省时记录为未提供。套餐标价、实付金额和录入时间各有含义，展示时使用相应标签。现有固定套餐在录入时确定，第三方无需选择套餐或数量。

## 影响与交付状态

ADR 0016 的飞书登录继续用于内部管理员；本决定新增独立的第三方凭据身份及服务端权限边界。沿用已有受保护会话、退出撤销、请求校验、限流和审计能力。私人项目资料继续受其访问授权约束。

订单和待送礼物需要能在账号及故事书尚未创建时存在。项目开通、更正及作废需要原子校验同一记录，使并发操作具有一个明确结果。现有创建故事书、主讲人、自购和首本权益逻辑复用至渠道路径。
