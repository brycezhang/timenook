# T21 · 接通书中原声码与版本固定的受控回听

2026-10-29 当前目标按 [ADR 0017](../../../adr/0017-lifetime-service-and-retention.md) 更新；长期规则及工程调整见 [#105](https://github.com/brycezhang/timenook/issues/105)；正式环境、设备及供应商验收仍按原责任票留证。

GitHub：[#22](https://github.com/brycezhang/timenook/issues/22) · 状态以 GitHub 为准。
阶段：S3

## 交付结果

读者扫描纸书入口，登录授权后只听到所印版本的原声；未授权者看不到私人信息。

## 验收条件

- [ ] 二维码只含随机稳定标识，入口与 book item 的有序音频清单固定，不指向最新稿、不包含姓名或访问凭据。
- [ ] 登录后每次解析/Range/下载重验身份、共享范围、安全授权有效期、删除状态和 epoch；未知者响应不含标题/缩略图。
- [ ] 经鉴权网关下载临时文件后播放，退出/播放结束按策略清理缓存，不重定向到可分享 OSS URL。
- [ ] 真机验证扫码、登录恢复、切账号、已印后在线改稿、长期回听与会话/授权失效；纸书与历史导出副本的边界明确。
- [ ] 回听及其原始录音按 ADR 0017 长期有效，时间推进或服务日期占位不停止解析/Range/下载，也不清理原声。Range 续传、换绑旧账号、会话/授权失效及主动撤回/删除仍重新核验；拒绝访问不伪报资料已删除。

## 实现边界

复用 T02 鉴权读取与 T04 稳定码能力，接入 T20 书稿音频清单及 T10 长期回听权益；真实书中入口和版本/权限变化单独验收，不复制文件网关。
