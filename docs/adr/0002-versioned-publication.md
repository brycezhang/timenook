# 以不可变故事和书稿版本驱动确认与生产

故事正文、照片与音频关联按版本追加；书稿冻结大纲版本、实际目录、完整素材清单与PDF hash。讲述者内容确认及发起人排版/地址确认绑定同一书稿，首本生产单和二维码引用该版文件及音频清单。

个人采访计划独立版本化，实际显示的问题保存快照。只修改未来问题不使故事确认失效；实际入书章节、顺序或内容变化使受影响的待生产书稿失效，重新生成并确认。模板更新不覆盖个人计划，已交付书稿不被在线编辑覆盖。

版本约束不阻止个人资料删除：按授权与保留规则清除内容和衍生文件，仅保留必要的最少审计事实。
