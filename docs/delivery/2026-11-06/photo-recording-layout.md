# 照片讲述的录音页面

2026-11-06 用户要求从图片开始讲述时，录音页面持续显示图片，限制图片最大高度以保留全部操作，并删除重复说明文字。

## 实现

- 照片起点的采访在进入录音页时读取同一采访的已保存照片，复用私有下载、摘要校验与临时预览清理。准备、录音和暂停期间均显示照片，多张照片可左右切换。
- 照片按比例完整显示；常规屏幕图片区域为 `32vh`，最大 260px。可用高度不超过 600px 时改为 `28vh`、最大 180px，并缩小录音按钮至 96px，保留 48px 暂停触控区。页面为可用视口高度，录音操作区使用剩余空间，底部预留安全区。
- 照片起点使用简短标题「看着照片，慢慢讲」，删除重复开场、说明卡、麦克风权限提示和自动上传说明。具体问题和后续追问继续使用实际问题；本次不修改服务端问题快照。
- 保留开始、结束、暂停/继续、必要错误提示和准备页「查看照片」。查看照片返回后仍停在录音准备页。
- 离开页面、切换账号或失权时清除图片及私人预览；迟到下载不回显。普通加载失败可重试。
