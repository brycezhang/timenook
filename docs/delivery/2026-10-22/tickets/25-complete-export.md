# T25 · 受理并交付可独立读取的完整资料导出

## 交付结果

用户申请后，客服核验范围并生成完整 ZIP，交付给获授权的申请人。

## 验收条件

- [ ] 管理端核验工单/范围，原声、原始转录、确认稿、照片、可交付 PDF、manifest 和可读说明齐全。
- [ ] 清单记录相对路径/hash/来源及版本关系，验证解压、文件数量、缺失文件与全部 hash，离开本平台仍能读取。
- [ ] 导出申请和包下载长期有效；打包完成和下载前再次检查当前权限、epoch、版本及安全授权有效期。发起人无导出授权不能领取，主动撤回/删除后旧包不可继续使用。
- [ ] 无微信讲述者走冻结的替代核验/交付通道；展示公示时限、实际状态及缺失原因，不额外收费。
- [ ] 验证跨时间、重试、重复领取及 Worker 重启后仍可申请、打包和下载完整资料；取消按服务期限清理有效包与来源资料。临时失败/孤儿包可按精确归属清理，不能误删有效包或支撑长期服务的源文件；主动删除继续逐层处理。
- [ ] 按 D08 适用规则检查确认稿、PDF、manifest 与可读说明中的 AI 整理/人工校对来源；与所导出的确定版本一致，真实原声独立标为原始录音，不误标合成；解压后仍可识别来源。

## 实现边界

客服核验后用受控打包工具完成首版人工导出服务，共享工单显示进度/结果；复用资产读取、T20 文件及 T15 耗时任务机制（需要异步时）。保留完整性、领取权限、技术残留清理与主动删除，不建自助导出编排平台。
