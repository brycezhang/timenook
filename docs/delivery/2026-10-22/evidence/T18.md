## 当前实现与公开边界

- 实际采访页的“整理或查看故事”携带真实 project/interview/assistedSession，进入故事页本身不提交生成。故事页明确提交后可回采访、选择“今天先到这里”、由现有项目的继续采访入口回来，恢复同一 task 和用户额度。开录/设备保存未完成时禁止该导航；本机已保存但未封存的片段可进入恢复页面，但不能提交不完整故事。账号变化后的旧采访不能导航。
- `POST /v1/projects/:id/stories/context` 恢复既有采访状态；`POST .../stories/organize` 在真实授权事务内冻结完整有序 sealed clip 列表、各自实际 question 快照/来源/planRevision、原声 intent/asset/hash/sealedInput、各转录依赖、偏好及 baseVersion。未封存云端意图和本机待保存内容明确恢复，不静默丢后半段。相同用户命令重放同一 Task；并发额度检查与 Outbox 同事务，Outbox 失败无半条用户意图。
- 单一 Worker 等待全部转录，等待任务让出到期批次，保留用户原始提交时间/Task/queuedAt。原声无有效语音时无 DeepSeek attempt、无故事稿。正式转录始终独立保存；输入清单不绑定 Interview 起始问题，可由后续真实 clip.actualQuestionId 消费追问回答。
- 复用 T03 DeepSeek transport、usage 与结构输出校验，增加本票实际多片段/实际问题/偏好输入。拒绝无效 JSON、空段落和清单外 sourceRefs，保留主题、reviewItems 与未确定事实。结果应用前在同一真实授权锁后复查 grant/epoch、全部输入、偏好、Story 版本与 Task fence；补录开始、偏好/版本变化或撤回后的迟到结果 obsolete，仍保留实际 attempt 观察及费用预留。
- Story/immutable revision/完整 source manifest 只有一个版本 owner；`Stories.appendIn(tx, expectedVersion, ...)` 是供生成与后续 T19 调用的公开事务内命令。调用方负责在同一事务内取得真实 Participation/processing 授权与项目锁；本票用真实授权事务追加版本验证 in-flight 竞争，没有私改数据库造业务状态，也没有为测试新增编辑 HTTP/UI。每个生成 Task 最多应用一个 AI revision；数据库复合 FK、不可变触发器及唯一索引保护范围和版本。
- 完整正文 `GET .../stories/:storyId` 受真实读取/共享授权保护。采集权限的 context/organize/task 仅返回安全进度；共享未授权时不返回正文或转录。共用 Task HTTP 保留 compose 的 sanitised observations/usage/model/failure，assisted retry 复查本次全部来源的真实 grant，不伪造单个 clip。
- 已知失败从原 task/原素材重试，新 provider attempt 但用户额度仅一次；主动重生成是独立用户命令。DeepSeek submitting/unknown 没有已验证 query 或 idempotency 保证，恢复进入人工接管，自动重提和换新 HTTP key 盲重提均被阻止。ASR 次数/poll 只按 ASR kind 计，项目货币预留汇总全部 provider attempt；unknown actualCost 保持 null，不编造费用。
- 默认/production 不接受合成生成配置。当前模型/提示词/预算上限只允许显式 synthetic-local 装配；没有把测试 fixture 冻结成生产政策。
- 故事页显示实际等待/生成/失败/接管/失效状态、全文、来源、AI/参与者来源标识与核对项。原声回听按冻结 intent 读取既有 Recording metadata，核对 project/interview/question/asset/sealedInput，再经同一 Session 受限下载实现读取真实 content，校验 bytes 与 SHA256 后播放。Photo 原方法签名兼容，新增 Recording 方法只构造三 UUID 的既有私有 content 路径；没有复制 token 或开放任意 URL 下载。
- Story show 只有一个当前 context 的 `onInvalidated` listener，hide/unload 注销并停止音频、清临时字节/私有呈现和 busy。跨页当前 401、本机到期迟到成功响应均不保留私屏；旧账号迟到音频 401 不伤后来账号。下载临时缓存与原始录音 manifest 分开，只删除下载 temp，不删除唯一 pending 原件。
