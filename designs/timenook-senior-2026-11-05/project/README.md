## 当前方案

1. 底部仅“岁月成书 / 我的”。无项目展示原有家庭大图、三项产品介绍和固定购买卡；购买或受邀参与项目后，首页展示当前项目。
2. “我的订单”统一改为“项目”，购买与参与的项目同处列表。首页独立二级页切换项目。
3. 微信邀请 → 接受邀请 → 直接进入项目。未登录时由“微信登录并接受邀请”一个按钮完成，不再中转独立登录页。项目成员可记录、编辑、预览与印刷；不设置身份审核、同机协助或本人专属功能。
4. 登录或接受邀请即同意使用条款，按钮旁明确说明并提供阅读入口。删除用途选择、独立制作授权及后续二次条款确认。
5. 录音结束自动上传，仅展示上传中、成功、失败重试。后台整理不阻塞用户离开，不暴露本机保存、封存等内部步骤。
6. 项目直接操作印刷：就绪书稿 → 地址 → 提交。无需讲述者本人/双方确认、翻完所有页、勾选或输入核对说明。
7. 退款、质量售后、资料与服务只在使用条款中说明，不再单设菜单。
8. 保留故事修改、照片、话题、书封、目录与正文编辑，以及付款恢复、生成失败、制作/物流和交付状态。

新故事整理完成后编入默认章节，可随时编辑或选择暂不入书。章节打开即显示本章故事的可编辑正文，保存同步对应故事版本；目录排序就在列表中按住右侧把手拖动操作。修改后生成新书稿，不要求重新进行本人确认。

## 视觉与交互

继续采用选定的米白、宋体标题、深色正文和橄榄绿按钮。390 × 844 画板；常规正文 20–22 px，主要按钮至少 60 px，章节拖动把手为 64 × 80 px，故事/照片拖动区至少 64 × 64 px。无折叠交互。

未购买首页保留原家庭大图和 72 px 固定购买卡；不恢复父母快捷入口，不显示“效果示意”标签。辅助说明与书稿中的旧品牌均统一为“时光故事”。

一个项目的故事、章节、书稿与寄送状态不随项目切换串用；新项目不继承旧项目资料。邀请加入与登录返回继续原任务。未保存编辑有继续/放弃提示。

## 拖动排序与点击分离

26「章节目录」移除右侧进入箭头及上移/下移按钮。章节名称区点击直接编辑；右侧单独划出拖动区，以分隔线、浅底色和“拖动”标识区分。故事与照片沿用同一手势。拖动时高亮并让位，松手更新顺序，边缘可自动滚动，手势取消恢复原顺序。普通内容区域仍可滚动；键盘方向键保留无障碍排序。
