## 实现边界

- 独立 AdminAccount/AdminSession 与受控建号 CLI；无注册 API、默认管理员或默认口令。local/production realm 分开，生产拒绝本地身份。
- 密码仅产生 MFA 挑战；标准 TOTP 完成后才发完整会话。挑战默认5分钟、完整会话绝对8小时，轮换/退出撤销，数据库持久化支持进程重启。重复与并发验证码由数据库事务和锁拒绝。
- 专用 `__Secure-timenook_admin` Cookie，Secure、HttpOnly、SameSite=Strict、host-only、Path=`/timenook/v1/admin`；写请求验证精确 Origin 和绑定当前会话的 CSRF。小程序 bearer 与管理员会话不能互用。
- 成功身份变更与审计同事务，提交后才设置 Cookie；审计故障回滚身份变更。失败审计不掩盖原鉴权结果。审计仅 operatorId/action/requestId/result/时间，不写正文、密码、token、验证码、TOTP seed、云 key 或完整地址。
- 最小 Vben 页面包含登录、MFA、运行信息与审计查看；仅 `ops:read` / `audit:read` 权限，无模板 CRUD、订单支付或私人内容浏览。

密码哈希采用带参数格式的 scrypt：N=32768、r=8、p=3、maxmem=64MiB、随机16字节盐。该32MiB/三次计算参数是 [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#scrypt) 列出的等价配置，用于控制共享服务器峰值内存；种子以 AES-256-GCM 加密。TOTP API 按 [otplib 官方文档](https://otplib.yeojz.dev/) 核实，依赖锁定13.5.0。
