# MP04 礼物分类、切书与家人邀请交付

2026-11-12：API、数据库、原生页面与现有 Web／Admin 消费者已完成。六张画板已补真实开发者工具 390px 截图，并走通邀请加入；320px 与补充交互继续由 MP12 验证。当前电脑可正常操作。没有部署、上传或提审。

## 已可操作

- 从「我的 → 我的礼物」查看我送出的、我收到的、我参与的；分类读取真实购买、指定领取和普通邀请事实。自购的同一个 projectId 在送出、收到都可进入，未复制项目或权益。
- 送出类同时恢复原待付款／付款结果未知的订单；行内使用真实书名、赠礼者昵称、购买时赠礼关系、故事数和金额。已购礼物按真实发卡／领取事实显示待送出、待领取、已送出。
- 从故事书首页切换故事书，复用同一分类与选择，使用原生 switchTab 返回首页。账号切换立即清空前一个账号的书、订单与分享状态；刷新保留同账号现有内容。
- 只有购买者可生成家人邀请。受邀者填写「你是主讲人的谁」，可选儿子／女儿／孙子／孙女／伴侣／自定义；同意条款后原地登录，再明确接受，加入同一项目。看条款返回保留表单；失效提示在本页显示。
- 购买者的关系资料可为空，项目功能正常；首次提问可用 [成员关系接口](MP04-contract.md) 补填。主讲人资料返回「本人」，不从赠礼关系反推。
- Web 邀请同步必填关系；后台关联项目包含普通成员和指定领礼人。成员关系已进入现有资料删除登记与触发器。
