# T09 · 后端内置单套默认大纲并复制为个人计划

GitHub：[#10](https://github.com/brycezhang/timenook/issues/10) · 状态以 GitHub 为准。
阶段：S1

## 交付结果

后端维护一套固定、中性的大纲与问题，创建项目时按模板版本复制为独立个人计划；用户无需先选模板即可开始。

## 验收条件

- [x] 默认章节/问题/目的以服务端代码常量维护，有稳定模板标识、版本和内容 hash；幂等初始化不可修改已存在的同版本内容。
- [ ] 默认起点不预设婚育或职业经历，保留照片/自由讲述；具体文案按 D09 原创/授权审校，未审校样本明确仅供测试。
- [x] 新项目固定引用当时的默认模板版本并复制计划；代码更新模板版本后，旧项目内容、个人修改与禁问偏好不改变。
- [x] MVP 不提供运营模板 CRUD/发布页面，也不提供多模板选择/推荐/切换；双方仍可修改自己的章节与问题。
- [x] 通过事务内公开项目创建模块验证默认起点、重复初始化、模板版本变更及项目隔离。

## 实现边界

保持代码内置一套默认模板，内容负责人审校后随代码版本发布；已有项目继续读取原版本，运营只提供文案审校，不增加全局模板 CRUD。
