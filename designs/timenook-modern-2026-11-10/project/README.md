# 时光故事 · 现代语音 App 设计

当前设计已与正式小程序源码逐项对照，见[2026-11-11 小程序实现差异](../../../docs/delivery/2026-11-11/miniprogram-design-gap.md)。清单区分可复用能力、待新增业务和界面调整；本轮只更新文档，业务代码未修改。

> 2026-11-11 已按确认的新需求更新原画布：71 张页面／状态、11 个分组。需求见 [REQUIREMENTS-2026-11-11.md](REQUIREMENTS-2026-11-11.md)，交互和手机排版走查见 [REVIEW.md](REVIEW.md)。

2026-11-10 全新设计。用户确认「明亮现代、照片叙事」，随后明确语音是主输入，沿用当前小程序的橄榄绿主色，页面、卡片与底部操作区统一白色。旧画布在本轮开始前已被移除，因此重新建立此画布；没有恢复旧视觉或覆盖业务实现。

## 已确认的设计

- 全页沿用首页的精简原则：导航保留功能标题，正文不重复同名标题；同一功能保留一个清晰入口。书稿封面与已回答故事卡片整块可点击；账号入口统一到底部「我的」。普通页面去掉重复返回，表单保存、录音控制和必要状态提示继续保留。
- 录音准备页整块麦克风与文字均可点击；登录弹窗通过关闭按钮原地取消。家人列表仅保留需要区分的「稍后回答」标签，字段选填标记与名称同行。

- 页面、卡片与底部操作区统一白色 #FFFFFF，使用留白与细边框区分层次；橄榄绿 #46563C 作为主色，深棕 #382C24 作为文字色，浅绿 #EDF0E7 用于回听控件、选中态等局部强调；中文使用系统无衬线字形。
- 橄榄绿主色、文字色与局部浅绿取自当前小程序 `miniprogram/styles/tokens.wxss` 与后加载的 `senior.wxss`，已对照本地正式构建产物。页面底色按用户本轮确认改为白色，礼物卡和书稿预览卡片同步使用白底。
- 390 × 844 手机画板，320px 窄屏可用。主按钮 52px，图标按钮 44px；内容独立滚动；首页「开始讲述」位于问题卡片内，随问题一起滚动，录音过程与提交页的操作保持底部布局。
- 回听统一使用可拖动进度条，显示已播放时间与总时长；播放/暂停保留位置、拖动定位、播放结束后可重播。故事原声与书中原声共用此交互。原型以计时模拟播放进度。
- 语音为主：讲述准备 → 开始、暂停、继续 → 结束自动保存 → 故事；补充以续录为主，文字校对为次入口。准备页并排展示无照片与有照片两种状态，支持添加、横向浏览和逐张移除本次讲述的照片；录音中添加照片先暂停并保留时长。照片随录音保存在故事中，不提供问题朗读功能。
- 从首页或讲述准备页进入「大纲目录」选题。默认六章，每章十题，共六十题；大纲与书稿目录共用章节，章节与问题均可增删改，章节可排序。章内分「问题」和「故事」，未回答的问题不会写入书稿。
- 送礼流程已于 2026-11-11 简化：指定收礼手机号后直接生成并分享电子礼物卡，移除语音祝福、同页文字留言与可选准备页。领取方验证手机号后明确接受，再点击「进入项目」打开项目首页；不再设置独立首讲页。书名、故事和照片在项目内管理。
- 首页和「我的」统一为送礼入口，赠礼关系必选。选「自己」后付款直接进入自己的故事书，不填写收礼手机号、不发卡、不领取。书籍与图片沿用新版示例资产，原十张效果图仅作为业务流程参考。
- 「我的礼物」分为我送出的、我收到的、我参与的。同一本送给自己的书在送出和收到两类显示，打开相同内容；普通受邀家人从参与类进入。书名下展示送礼人昵称和购买时的赠礼关系。
- 家人提问保留独立入口，也进入首页随机推荐：先展示家人题，按约 2:1 穿插大纲题，本轮不重复；已回答、跳过不推荐，稍后回答本次略过、再次进入故事书可重现。家人提问仍仅文字输入，章节可选，语音回答后关联故事。
- 家人问题统一显示「女儿 · 小雨的提问」这样的关系与昵称，覆盖首页、列表、详情和讲述页，始终跟随原提问人。加入时填写自己相对主讲人的关系；购买者首次提问缺少关系时补填。
- 未选章节的回答直接保存为故事，可从故事详情、未归章列表或任一章节的「本章故事」随时归章。未归章故事不阻塞生成 PDF，书稿只收录章节内的故事，其余仍保留。
- 全部页面使用功能或状态标题，统一导航栏、页面主标题、空状态、异常状态和画布名称，例如「故事列表」「故事整理失败」「编辑封面」「书籍已寄出」。书名、故事名、录音问题与书内正文继续展示内容本身；次要说明保持简短。
- 书稿预览对齐现有 PDF 方案：章节管理 → 生成 PDF → 书稿信息 → 使用微信文档查看器打开。修改后须重新生成；目录随 PDF 只读展示。原声二维码对应固定故事版本，扫码并完成登录及权限核验后回听。原型补充 PDF 内容示意，移除自定义翻页与 PDF 内直接播放按钮。
- 章节按现有小程序实现设计：章节管理可拖动整章，并显示所属故事；编辑章节修改名称与正文；「本章故事」独立完成选取、章内拖动与移出。跨章操作使用「移到本章」，移除章节或故事引用均保留项目故事。
- 登录采用底部弹窗，保留当前页面；关闭不跳转。最新备注调整：协议未勾选时登录按钮仍可点击，点击后提示「继续登录表示同意协议」；点击「继续」即确认同意并直接继续微信手机号登录，无需重复勾选或点击登录，取消则原地停留；已勾选直接登录。首页与购买登录后继续原操作，「我的」登录后显示账号；查看条款后返回原弹窗。本次仅同步文档，画布交互与业务代码待更新。
- 故事书首页删除独立的故事／书稿／照片按钮；故事数进入故事列表，照片数进入照片列表，书名、赠礼副标题与封面组成的整块区域进入书稿。问题与「开始讲述」合为一个卡片。
- 项目首页的原声总时长以整数分钟展示，按四舍五入计算；不足一分钟显示「<1 分钟原声」，零录音显示「0 分钟原声」。播放器仍保留精确到秒的进度。
- 画板标题统一为「序号 角色｜功能」：区分所有人、未登录用户、已登录用户、送礼人、购买者、收礼人、项目成员和受邀家人。手机页面内保留简洁功能标题；共用页面标注共同角色，不复制页面。
- 项目成员可记录、编辑和提交制作；发起家人邀请仅限项目购买者。收礼人与已加入家人的首页隐藏邀请入口。接受家人邀请时必须填写「你是主讲人的谁」，关系不改变权限。
- 本轮整体走查修复原型中的跨项目状态串用：旧待付款订单不修改当前项目，后台录音保存回原项目，补录累计时长；未保存封面编辑可取消，已提交制作的书稿版本保持固定。
- 71 张可交互页面／状态，11 组；页面列表以 canvas.json 为准。每张画板可以独立开始，也可从 Main 完整走主线。

## 业务路径

详见 [BUSINESS-FLOW.md](BUSINESS-FLOW.md)。现行规则依据 ADR 0018 与 ADR 0020，最新录音额度依据 CONTEXT.md 的 2026-11-10 决定。录音单段 10 分钟，可在同一故事续录；购买时不收地址，完成书稿后提交制作。

## 原型边界

本画布为设计与点击演示。微信登录、支付、手机号核对、分享、麦克风、语音转写和音频回听均为样例状态，不会联系真实微信好友，不会收款或录制麦克风。家人提问为文字输入；主讲人回答仍以语音为主。

录音计时与保存/整理过程可操作，输出的是明确虚构的示例故事。人物照片由图像生成工具制作，不是真实用户资料。电子礼物卡先验证指定手机号，明确接受后进入既有项目。错误、失效、处理中、制作与交付均可在对应画板查看。正式服务采用完整当前条款；条款页展示信息组织，不构成新的服务承诺。

PDF 查看器画板仅展示系统打开文档后的内容示意，不生成或下载真实 PDF，也不承诺微信各设备的控件外观。书内二维码编码为「时光故事｜设计示例｜非真实录音入口」，不含真实地址、会话或私人信息。

设计稿不替代小程序真机、真实手机号授权、支付、录音或实体印刷验收。
