# T24 · 贯通撤回、活动流终止与生产暂停

GitHub：[#25](https://github.com/brycezhang/timenook/issues/25) · 状态以 GitHub 为准。
阶段：S4

## 交付结果

讲述者撤回指定用途后立即停止相关访问与新处理，并能看见待生产或已交接事项的实际处置进度。

## 验收条件

- [ ] 复用基础授权命令，先提交拒绝访问和 epoch，再取消任务/冻结生产；活动下载流关闭，受控客户端缓存清理。
- [ ] 同一项目的确认、结果提交、首本提交、交接与撤回竞态均验证，迟到任务不能重建或激活内容。
- [ ] 本人/协助/客服核验通道均执行相同范围规则；发起人付款身份不能撤销讲述者选择。
- [ ] 页面明确可停止事项、供应商待确认事项和已导出/纸书边界；保留最少审计，不声称已收回设备已传输字节。
- [ ] 把 T11 换绑导致的 epoch 更新接入现有项目访问控制：旧账号活动访问终止，旧请求和迟到结果按当前授权拒绝；保留原 subject/历史确认，不能将换绑误当作全项目删除或新项目。

## 实现边界

复用 T11 权限/epoch 与 T15 任务执行约束，补活动流和生产联动；有效撤回立即止访，外部取消由人工联系核实，不能以等待客服为由继续访问。
