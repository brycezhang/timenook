# T01 工程基础验收

关联：[Issue #2](https://github.com/brycezhang/timenook/issues/2)。对照基线：e0abe7b。日期：2026-10-22。

## 实现

保留现有小程序源码和预览路径，迁移 npm 锁文件为 pnpm workspace；增加 NestJS/Fastify API、公开契约、Prisma 迁移、独立本地容器和 Linux CI。初始 schema 仅包含基础设施版本标记，没有预建业务表。

模板范围已在 ADR 0008 调整为后端单套固定模板；其实际实现属于 T09，本票没有加入运营模板页面或业务模板数据。

## 验证证据

| 项目              | 结果                                                                                              |
| ----------------- | ------------------------------------------------------------------------------------------------- |
| 工具链            | Node 22.23.4 / pnpm 10.34.7；官方 Node 下载归档 SHA256 已核对                                     |
| 本地依赖          | PostgreSQL 16.13 / Redis 7.4.8；独立 Compose 项目与卷、镜像 digest 固定                           |
| Prisma            | 6.19.3 generate 与初始 migrate deploy 通过                                                        |
| pnpm check        | 前端类型、23 项现有行为测试、12 项 API/启动测试通过；15 页小程序、Vite 预览与后端构建通过         |
| pnpm check:native | Mac 微信开发者工具 wcc/wcsc 编译 15 页通过                                                        |
| pnpm api:openapi  | 导出成功，健康响应与 503 标准错误契约可读取                                                       |
| 实际进程故障恢复  | 同一 API 进程下分别停止 Redis/PostgreSQL：ready=503、live=200；依赖恢复后 ready=200，无需重启 API |
| 停机              | SIGTERM 后 API 释放资源，退出码 0                                                                 |
| 迁移缺失          | 数据库可连但目标 schema 未迁移时返回 503                                                          |
| 配置与隐私        | 缺少连接配置、无效 URL/端口、生产示例密码拒绝启动；错误响应不包含连接串；生产不开放 OpenAPI 路由  |

新增测试先观察缺失实现、就绪端点 404、503 错误结构缺失、启动配置检查缺失和 OpenAPI 404，再逐条实现。数据库状态通过公开 HTTP 边界验证，不以 mock 证明就绪。

前端核心依赖版本与原 npm 锁文件逐项核对：Vite、tsx、TypeScript、esbuild 与 miniprogram-api-typings 未随迁移升级。
