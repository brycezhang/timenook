## 集成中修复

- WebKit 实际录音触发 IndexedDB `Error preparing Blob/File data`，改为将原始 MP3 字节和元数据一同提交，读取后恢复 Blob，刷新/重试沿用同一录音与摘要。
- 照片起点首篇故事保存同采访的确定照片快照；后续照片说明变化不覆盖已保存版本。
- 故事原声按版本 manifest 的 `intentId` 访问录音入口，避免把 `RecordingClip` ID 误作 `RecordingIntent` ID；实际解码/播放验证，不仅检查区域可见。
- 产品构建补齐编码器许可与对应源码；构建测试校验公开文件与排除原型认证控制。
- CI 原生构建断言曾把正式条款中的“网页同号账号”解释误判为演示入口，现保留全部演示标记/路由禁用与 `web-view` 禁用，同时允许条款解释已确认的双端政策。

## 工程检查

当前最终定向入口：`pnpm test:web-mvp`。它构建真实应用，运行 HTTPS、公开 HTTP、独立 PostgreSQL schema、Redis、Worker、实际 MP3/PDF；只替换外部供应商与设备输入。Chromium 与 WebKit 覆盖首页/登录、故事邀请、录音恢复、照片、书稿、支付宝和制作路径；320px 与桌面布局另检查。

当前 17 项构建后整站场景已分段通过：首次完整命令 15 项通过，2 项书稿新增断言误以手机视口检查桌面专属封面区域；测试按实际布局改为桌面视口后，书稿 Chromium/WebKit 2/2 定向复测通过，业务实现未因此调整。原整站结果与定向复测分别保留，不宣称一次全绿的完整命令。

最终固定代码审查：规范轴无可操作问题；规格轴发现制作页收到 403/404 后保留收货/物流资料，正在用真实成员撤销验证并补齐局部清理。普通网络失败继续保留已加载内容。修复及其回归结果另追加。

此前 API 各分片、后台浏览器与官网 CI 已通过，构建任务暴露上述正式条款误判；定向原生构建断言修正后通过。最终 PR CI 以最终提交结果为准，未把旧失败或取消运行计为通过。各切片定向结果不作为真实供应商或手机证明。
