# 多页按钮间距

关联 [#137](https://github.com/brycezhang/timenook/issues/137)，沿用已有视觉与共用 WXML/WXSS。按照 baoyu-design 的接近性、留白与移动触控原则，给连续操作显式分组，不调整事件、授权、禁用状态或横向工具栏。

## 实现

- 主操作纵向间距 `24rpx`，正文/操作与主次操作分组 `32rpx`，次要文字操作间距 `12rpx`。以 375px 页面为例分别为 12/16/6px，随页面宽度缩放。
- 共用文字按钮和紧凑按钮最小高度 `44px`；真实首页、账号关联、邀请、同机协助、讲述、故事、书稿和订单使用上述间距。
- 新版官方开发者工具采用 Electron 目录，原生编译检查的默认 `wcc-exec` 路径同步到已安装版本，保留显式环境变量配置。
