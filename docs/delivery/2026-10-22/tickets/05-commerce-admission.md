# T05 · 冻结销售参数并核验实际微信支付路径

## 交付结果

形成可审核的套餐发布参数及真实商品准入证据，让后续支付实现有明确输入和不开售条件。

## 验收条件

- [ ] 记录实际主体/AppID/商户绑定、商品类目与数字制作加实体书销售路径、双端支付和发货管理核验结论。
- [ ] 冻结 D02 制作权益、D03 资料期限、D04 额度/成本、D05 配送、D06 人工时限、D07 退款及 D08 身份/授权/供应商准入；D01、D09、D10 由各自票据独立冻结，不作为本票的回环依赖。
- [ ] 明确无微信讲述者的同机证据、争议处理、导出与删除通道，以及运营负责人；不把付款当作本人授权。
- [x] 提供配置完整性核验清单；未冻结或未获准的参数保持未通过，技术试验值不写成销售承诺。
- [ ] D02/D03 明确起算事件、未参与处理、暂停时钟/上限、到期动作与各类副本期限；D08 明确客服换绑证据及 PDF/导出标识适用方案。决策未冻结保持待定，完整性检查不证明规则已执行。
