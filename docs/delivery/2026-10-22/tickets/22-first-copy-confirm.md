# T22 · 双方确认同一 PDF 并唯一预留首本制作

2026-10-29 当前目标按 [ADR 0017](../../../adr/0017-lifetime-service-and-retention.md) 更新；长期规则及工程调整见 [#105](https://github.com/brycezhang/timenook/issues/105)；正式环境、设备及供应商验收仍按原责任票留证。

GitHub：[#23](https://github.com/brycezhang/timenook/issues/23) · 状态以 GitHub 为准。
阶段：S3

## 交付结果

讲述者确认内容，发起人确认完整 PDF 与地址后，提交首本且无需再次付款。

## 验收条件

- [ ] 双方确认绑定同一 book version/snapshot hash/PDF hash，发起人另绑定地址 hash；内容或地址变化使对应确认失效。
- [ ] 事务检查真实付款、权益、当前书稿、全部故事许可、授权/删除/退款冻结、生产规格及双方确认。
- [ ] 同键重复返回原生产单，异载荷冲突；不同键并发仍只预留同一权益和首本生产单，管理端审核不能绕过。
- [ ] 页面显示已付999元、制作1本、本次无需支付及约定配送信息；未确认/旧版/超规格均阻止提交。
- [ ] 提交首本与审核按 ADR 0017 长期有效，时间推进不阻止发起制作，不创建到期审核工单；移除到期审核入口及服务计时暂停/恢复操作。并发提交仍只预留唯一首本，付款、双方同版确认、当前授权及商业冻结检查继续有效。

## 实现边界

复用 T10 长期权益和 T20 书稿快照。生产审核仍核对双方同版确认、唯一预留及当前授权；客服工单承担退款、质量售后和资料申请等实际服务事项，不再承担服务到期审核。
