# T28 · 闭环质量售后与原单重印

GitHub：[#29](https://github.com/brycezhang/timenook/issues/29) · 状态以 GitHub 为准。
阶段：S4

## 交付结果

用户提交质量问题后，客服可核对确定 PDF、印刷及物流证据，处理赔付或原单重印。

## 验收条件

- [ ] 工单关联原订单、生产尝试、PDF hash、物流和质量证据，最小权限查看私人内容且有有效期/审计。
- [ ] 重印属于原首本生产单的新尝试，不新增购买或额外首本权益；不得出现两个并行有效交接。
- [ ] 重印若修改正文/排版，重新生成书稿并取得双方确认；原文件重印也核验授权与实际取消/接单状态。
- [ ] 展示处理人、时限、进展和结果；涉及退款调用同一退款用例，不人工写成功状态。

## 实现边界

沿用 T23 生产尝试、T27 退款和共享工单；人工判定质量责任及救济，系统保证原单重印、唯一交接与必要重确认，不新增独立售后平台。
