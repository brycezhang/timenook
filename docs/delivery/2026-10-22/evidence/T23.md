## 本地结果

增量 RED/GREEN 与受影响回归分别记录于[后端](T23-backend.md)和[前端](T23-frontend.md)。最终固定提交的独立 Standards/Spec 审查、PR CI 和精确 main CI 以 GitHub 交付记录为准。

浏览器目标为「运营建立尝试 → 本人限时授权 → 核对同一 PDF → 人工交接待核实 → 明确接单 → 物流及微信发货记录 → 唯一交付」。Browser plugin not available；使用仓库 Playwright 连接真实 Page/Vben、HTTP、PostgreSQL/Redis 与合成样本生成的实际 PDF。小样本沿用 T22 独立合成套餐的 `minPages=1, bleedMm=0`，默认销售规格保持不变。
