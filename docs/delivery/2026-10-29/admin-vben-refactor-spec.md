# 管理后台 Vben 整体重构与长期服务

状态：2026-10-29，用户已确认整体重构、搜索/筛选/分页及详情交互、多标签页，并明确长期服务规则。本文为可审阅规格草案；测试入口与拆票待本轮确认，尚未发布新父 issue，未实施或部署。长期服务决定已写入 [ADR 0017](../../adr/0017-lifetime-service-and-retention.md)。

2026-10-30 合并整理：长期服务规则已由 [#105](https://github.com/brycezhang/timenook/issues/105) 完成工程调整，当前实现见[长期服务说明](../../development-lifetime-service.md)，已有同域受控运行结果见[网页运行验收](mobile-web-online.md)。下文保留整体后台的目标设计；后续消费这些已交付契约，补验受影响部分，不把它们重新标为未实施。Vben 布局与业务页的整体重构仍是待实施规划。

## 问题与结果

现有后台通过内存变量切换功能，侧栏只有静态入口，登录页、表单和内容容器缺少完整 Vben 应用组织。运营无法通过明确 URL 直接进入详情、刷新恢复位置，长页面中的查询与操作也难以区分。项目原有有限服务期还贯穿录音、首本制作、回听、完整导出和资料清理，与用户现在确认的长期服务相冲突。

后台按 wutong 的 Vben web-antd 路线采用完整认证布局、主布局、路由菜单、面包屑、权限及多标签页。各业务提供统一列表、搜索、筛选、分页、详情和操作弹窗/抽屉。同步将制作、回听、下载和必要资料保留改为长期有效，移除服务期限及例外审核入口。

## 已确认的范围

| 菜单分组 | 页面与用途 |
| --- | --- |
| 商品配置 | 赠礼关系；套餐版本、草稿、校验与不可变预览 |
| 客户服务 | 客服工单；退款、质量售后、资料申请、换绑及必要校对按工单类型进入详情 |
| 生产履约 | 生产单；确定 PDF、人工交接、生产进度及物流登记 |
| 系统运维 | 处理任务；运行状态；操作审计 |

采用时光里现有品牌。登录页使用 Vben 认证布局并保留飞书唯一登录入口；登录协议按 ADR 0016 继续使用当前服务端保密客户端方案。启用多标签页；复杂工单/生产详情有独立 URL，短编辑和确认使用弹窗/抽屉。用户可使用浏览器前进/后退、刷新和复制详情链接，菜单/面包屑/标签保持一致。

工程默认：沿用运行状态为默认首页；账号无该权限时进入其第一个有权页面，没有权限时显示明确无权限页。不新增未经确认的经营数据看板。桌面为主要操作界面，窄屏菜单可收起、表格可横向滚动，主要操作可用。

## 实现决策

### 完整 Vben 应用组织

固定框架来源和许可证，扩展当前裁剪包至实际所需的应用布局、菜单、权限、状态、通用页面和表单/弹层依赖。参考 wutong 的组织方式，使用 Vben 的完整认证/主布局及通用页面组件、Ant Design 表格/表单与必要适配；不以引入依赖名替代真实接入。wutong 当前关闭标签页，本项目按用户决定启用。表格按现有技术路线选用统一适配，不要求为了名称全量更换为 VXE。

路由定义统一提供菜单、标题、图标、面包屑、标签及权限信息。业务模块按需加载；认证、会话与全局错误统一管理。后台以现有 `/admin/` 为入口，使用正常页面 URL；嵌套地址的静态服务回退、同源 API 路径和登录回跳一起验证。回跳仅接受本应用允许的路径，服务端鉴权继续为最终依据。

保留 TimeNook 的 HttpOnly/Secure Cookie、CSRF、白名单及权限码。会话不复制为浏览器持久化 token。标签栏只保存必要路由元数据，私人文件、正文、授权凭证不持久化；私密详情默认不保活，切换时重新检查权限，失效/退出清理所有已打开页面中的私密状态、下载与预览。晚到响应不能重新填回旧页面。

列表沿各业务独立查询入口补齐过滤、稳定排序和分页；权限、资源范围、页长上限及参数校验在服务端执行，前端不把有限的最近记录当成全量数据。仅小型固定目录可明确使用完整返回数据的本地筛选。列表回退状态存放非敏感路由参数；详情按 ID 重新鉴权加载，表单校验复用当前业务契约。全站统一标题、工具栏、表格、空状态、加载及错误反馈。

### 长期服务与资料

[ADR 0017](../../adr/0017-lifetime-service-and-retention.md) 为长期业务语义的唯一依据。新政策直接表达长期有效；当前项目服务记录没有强制到期日期字段，无需为此人为新增日期。只有无法省略的底层业务日期才固定 `2099-12-31`，仍不得作为真正截止时间。

同时更新套餐准入、告知、中央资格判定、用户端/后台及所有消费方。移除服务期限菜单、表单、权限码、操作接口和到期审核工单类型；保留退款冻结、争议处置、主动撤回引起的生产暂停等实际约束。本次开发重构直接按新模型硬更新，必要时重建相关开发数据和测试夹具；不做旧数据迁移、历史有限期兼容、旧备份/旧台账恢复、备份准备或回滚演练，也不为这些旧开发场景保留测试。新规则下的主动撤回、删除、权限校验及进程重启后的正确行为仍须验证。

取消类别保留期和完整包下载期的自动删除触发；覆盖 API 定时扫描、Worker 恢复扫描、打包完成、流式下载及孤儿包识别。长期有效包不得因到期字段为空或占位而被当成孤儿。正式资料及必要关联长期保留；技术暂存/失败残留仍按真实归属安全清理。当前模型下的主动撤回/删除继续形成拒绝依据，迟到任务不能重建被删除内容；旧开发台账格式无需兼容。

首次实际切换前核实对象存储生命周期、新政策/包记录和后台扫描入口，所有必要资料保护必须与长期访问能力配套交付。工程中间提交不作为完整长期服务上线依据。

### 业务与交付边界

保持现有授权、原单资金/权益、版本确认、幂等和人工交接约束。D06 处理 SLA、D07 退款/质量窗口及安全 TTL 分别执行；这些规则的具体未定值仍按原责任票核实。生产页面沿已定的“PDF 书稿完成 → 已生产 → 已发货/物流”表达，完成印制必须有独立实际事实，不能只把接单改名为已生产；必要最少记录随生产票补齐，仍由运营线下核实。

## 测试决策（待确认）

测试以用户能观察的公开行为为主：现有 HTTPS 浏览器流程 + 实际 API + 真实 PostgreSQL/Redis；小程序使用现有页面/服务公开行为入口，既有真实设备、供应商和实物验收独立留证。供应商外部网络允许隔离替身，锁、事务、主动删除及进程重启使用真实依赖。对低风险样式采用浏览器尺寸/交互检查和无凭据截图，不增加只复述组件实现的单元测试。

| 入口 | 必验行为 |
| --- | --- |
| HTTPS 管理端 | 飞书登录/回跳、取消与失效、权限菜单及直达 URL、刷新/前进后退、403/404、多个标签及退出清理、桌面/窄屏布局 |
| 列表与详情 HTTP + 浏览器 | 超过旧最近 100 条的数据仍可查询；组合筛选/分页/稳定排序/返回定位；空结果/失败/重试；越权、重复提交及版本冲突 |
| 长期资格与制作 HTTP | 推进时间越过旧截止及占位日期仍可录音、确认与提交首本；原有唯一权益/付款/退款冻结/版本授权仍有效；旧期限操作不再可用 |
| 受控媒体与完整导出 | 纸书回听、照片、故事/PDF、导出申请及已完成 ZIP 长期可用；临时授权到期可重新鉴权；无时间计数溢出；未授权/主动撤回/删除仍拒绝并终止流 |
| 删除、调度及重启 | API 定时器与 Worker 扫描不产生业务到期删除；有效长期包不被孤儿清理；主动删除仍逐层完成；迟到输出不会重新生成被删除资料 |
| 实际环境 | 正式对象 lifecycle、新模型与开发数据、同域嵌套 URL、真实飞书回跳及清理配置；结果不能由合成测试替代 |

复用既有支付/首本、原声/书稿、完整导出、主动删除及管理浏览器用例，把旧有限期断言改成新的公开规则，同时保留未受影响的权限和一致性断言。按根 AGENTS.md 的功能实现优先约定，执行变更所需的定向检查和仓库必要 CI；已有有效验证直接复用，实际环境验收单独记录。

## 范围外

旧开发数据迁移、旧备份/旧台账兼容、备份准备、回滚和旧版本恢复演练不纳入本次重构，不作为实施或环境切换前置条件。

新增经营看板、独立用户/角色管理产品、通用政策编辑器、自动印厂/物流接口、新售卖或支付通道、无限内容额度与额外首本、自动批准售后，以及把技术凭证改成永久凭证。历史真实证据保留为当时事实，不自动追认新规则通过；T29/T30 的既有外部验收继续由原责任票负责。
