# 小程序新购误查旧订单

新购确认页原先按账号读取最近的下单意图。即使服务端已经返回订单号，缓存仍会被下一次新购读到，主按钮随即显示「查询购买结果」，点击后查询的是上一笔订单。

现在只在建单结果未知时保留请求和幂等键。服务端返回订单号后，当前确认页继续跟踪该笔订单，新购确认页可创建新单。待付款可在「我的项目」打开并继续支付。下单结果未知时，显式查询会沿用原请求和幂等键。
