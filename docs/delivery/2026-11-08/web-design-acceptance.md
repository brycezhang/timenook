# 网页设计验收

2026-11-08，对照 [Vue 新设计稿](../../../designs/timenook-web-2026-11-07/README.md)与当前公开产品网页 `https://sgl.wootoon.cn/app/`。结论：**设计验收未通过，剩余 2 项 P1 和 3 项 P2**。功能交付、实际短信/支付的既有验收与本次视觉还原结果分别记录。

本轮按用户新要求精简解释性文案，已合入 main 并发布网页静态包：`18d3173` 删除重复说明，`aa47910` 保持账号操作分行。新要求覆盖原型里冗长的说明，不要求把这些文字恢复到正式页面。API/Worker 沿用既有发布，没有修改认证、付款或项目归属规则。

## 依据与方法

- 设计依据：`designs/timenook-web-2026-11-07/` 的当前 Vue 原型与 `design-system/project/tokens.json`；本轮实际打开并重新截图，没有使用历史缓存截图作为验收证据。
- 使用用户允许的 Playwright。重点为 Chromium 320×568、390×844，补查公开页 768×844、1440×844；WebKit 320×568 复现录音入口问题。桌面浏览器尺寸模拟不等于 iPhone/Android 真机验收。
- 公共页面匿名访问；私人页面使用隔离的虚构内容账号及临时空账号，真实 HTTP/API/数据库返回，没有替换业务响应。运维签发的临时会话仅用于设计取证，不作为短信登录证据。本轮未操作用户已有的两个项目，未发送新短信、下单或付款。
- 本轮截图保存在本机 `output/playwright/design-audit-20261108/`（Git 忽略）；`gallery.md` 提供设计稿/线上配对截图，`final-metrics.json` 记录脱敏布局测量。全页截图中的固定底栏位于取图时的视口位置；判断遮挡使用独立视口截图和元素坐标。

## 已完成的文案精简

登录弹窗移除欢迎副标题、同号账号说明和重复隐私脚注；首页、项目列表、我的移除账号互通说明；录音、照片、故事编辑、原声、书稿、购买和制作页删除重复的介绍与操作解释，并清理失效样式。保留字段标签、条款同意、样书示例标识、格式/大小约束、错误与处理状态、实际付款/印刷的必要约定。

320px 登录弹窗从约 533px 缩为 416px；出现手机号校验错误时为 450px，登录按钮仍完整可见。输入框为 16px，条款默认未勾选，使用原生模态弹窗。类型检查、构建、定向浏览器取证通过；文案/样式改动未新增形式化测试或重复全量业务回归。

## 待修复

### F1 · P1 · 全局导航与登录后首页没有还原

设计稿提供首页、故事、书稿、项目、我的五项导航。成员首页显示当前项目、统计、开始讲述、最近故事和推荐话题；空账号首页有开始第一本书的明确入口。

线上手机底栏及桌面侧栏只有岁月成书、我的项目、我的三项。已有项目和空账号回到 `/app/` 都显示产品介绍，故事/书稿需要先进入项目才能找到；空账号没有稿件中的首次开始区域。用户原先审阅的工作台没有落地，不能仅凭颜色相近判为通过。

代码定位：`apps/web/src/App.vue`、`apps/web/src/views/Home.vue`、`apps/web/src/router.ts`。修复应使用真实选中项目与空态，不引入状态预览或示例个人项目。

证据：`reference-member-home-390.png` / `final-member-home-390.png`；`reference-empty-viewport-390.png` / `final-empty-home-viewport-390.png`。

### F2 · P1 · 320px 录音主操作仍在首屏以下

设计稿在 320×568 可直接看到计时和开始录音。线上话题列表占据首屏，精简文案后按钮仍位于 `y=727.7–773.7`，底栏从 `y=503` 开始，首屏完全看不到按钮。Chromium 与 WebKit 均复现。390×844 已改善为按钮 `y=682.9–728.9`，位于底栏 `y=779` 之上。

代码定位：`apps/web/src/views/Recording.vue` 的话题列表与录音控件，以及 `apps/web/src/recording.css`。应优先保证题目、计时和主要操作可见，将选题列表压缩或折叠；不能以删除题目数据代替布局修复。暂停/结束状态仍需在后续修复时一起检查。

证据：`reference-record-320.png` / `final-record-viewport-320.png`；`final-record-webkit-320.png`。

### F3 · P2 · 书稿封面版式及编辑层级偏离稿件

稿件为外层浅色预览框、白色纸张、居中书名/寄语和照片，封面编辑由明确入口展开。线上使用沙色书脊式大封面，寄语位于照片之后，书名/寄语编辑表单常驻预览下方，目录和生成操作被继续向下推。

照片替换树苗的要求已满足；本项针对版式与层级。示例人物、故事数量和实际照片内容不同不算缺陷。应保留现有真实照片、目录和 PDF 能力，将预览与编辑组织回已定设计。

代码定位：`apps/web/src/views/Book.vue`、`apps/web/src/book.css`。证据：`reference-book-390.png` / `final-book-390.png`。

### F4 · P2 · 首页字号与主按钮层级未对齐

390px 设计稿主标题为 34px / 51px，线上为 36px / 55.8px，同宽 350px 下最后一个“书”单独成行。套餐主按钮也由稿件的满宽操作变成与服务约定并排的小按钮。320px、1440px 的字号和照片说明位置也有差异。

应按稿件校准断点字号、行高、按钮宽度与间距；按用户要求删掉的解释文字不属于待恢复内容。代码定位：`apps/web/src/style.css`、`apps/web/src/views/Home.vue`。

证据：`reference-guest-390.png` / `final-guest-390.png`；同宽 768px、1440px 配对截图。

### F5 · P2 · 昵称弹窗没有管理键盘焦点

打开修改昵称后，焦点仍停留在背景触发按钮，Tab 会先经过背景“我的项目”“新购一本书”“退出登录”等控件；按 Escape 后弹窗仍开着。运行时 `dialog:modal` 为 false，昵称输入框字号为 12px。

代码使用 `:open="editing"`，没有采用登录弹窗现有的 `showModal()` 模式。应统一焦点进入/约束、Escape 关闭和关闭后返回触发位置，并提升手机输入字号。本项由实际键盘操作确认；不据此宣称完整 WCAG 或真机读屏验收。

代码定位：`apps/web/src/views/Account.vue`。证据：`final-nickname-390.png` 及本轮 Tab/Escape 记录。

## 已确认的共同基础与边界

12 个品牌颜色与新设计 token 一致；已测页面没有横向溢出；正式网页不存在“状态预览”控制。图片封面、真实内容读取及基本动作入口已有实现。项目卡片和个人页仍有密度/结构差异，可在 F1 与 F3 调整时统一，不另扩展业务范围。

本轮未重测短信/真实资金、手机麦克风、录音中断、系统键盘、安全区、读屏、印厂或物流。照片/PDF/原声只是检查现有内容与入口，没有重新上传、生成书稿或编辑真实资料。临时会话及空账号在取证后清理，私人会话文件不进入 Git。

网页发布目录：`/data/server/timenook-web/releases/20261108-web-copy-aa47910`。公网 HTML 已引用本地构建对应的 JS/CSS；本轮只替换网页静态资源，未重启或更新 API/Worker。
