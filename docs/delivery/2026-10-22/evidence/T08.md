## 本轮可运行边界

- 关系按 realm 与 code 唯一，新增、排序、启停及修改称呼通过真实管理 API；code 不可修改，revision CAS 防止覆盖。默认无 seed。公开选择合同支持目录 code/revision 或项目自定义称呼；自定义不写全局目录，不推断性别、经历、身份或权限。本轮不实现订单、付款和项目持久化。
- 套餐草稿允许缺参，管理端可保存、重新打开及导入受限 JSON。完整性复用 T05 `validateSalesAdmission`，仅补 D01 印刷参数与精确覆盖配送地区的公开名称映射。没有擅设期限、额度、印刷默认值，没有修改真实 `commerce-decisions.json`。
- `POST .../preview-versions` 仅在非生产 realm 冻结 `local_preview`。结构完整与审批真实性、销售授权分开：`approval: not_verified`、`salesAuthorized: false`；公开 `purchasable` 恒 false。没有占位 publish 接口或可绕过生产的测试销售开关。真实发布/销售启用仍是 #9 待完成项。
- PostgreSQL 锁定草稿修订，`(realm,draft_id,draft_revision)` 唯一；同修订重放/并发复用一个版本，新修订追加新版本，数据库触发器拒绝旧版本 UPDATE/DELETE。旧版内容/hash 在进程重启后保持一致。生产拒绝预览冻结且不读 local 目录/版本。
- 写入与成功审计在同一事务中；重新核验会话状态和权限，检查 Origin、绑定会话的 CSRF。`catalog:read`、`catalog:write`、`catalog:freeze` 分开，`ops:read` 不授予写权。失败审计不包含输入正文，审计故障回滚业务变更，重试不写两遍。
- 小程序 live 读取两个真实公开 GET，展示动态/自定义赠礼称呼、同一 99900 fen/CNY 价格、一项目/一成年讲述者/一发起人/首本一本、约定运费和完整导出、配送/期限/退款说明。地区用受限公开名称，照片用“张”、录音用“秒”。消费者文案为“套餐准备中，暂未开放购买”。
- 公共 DTO 通过白名单生成，不透传 admission、私人证据、负责人、成本预算、商户/AppID 或供应商材料。刷新失败清除旧套餐，明确重试；页面隐藏、切换模式、刷新竞态丢弃过期结果。live 不回退 demo、不创建演示项目、不调用微信付款。浏览器 shim 仅桥接两个公开 GET，不伪造微信登录。
