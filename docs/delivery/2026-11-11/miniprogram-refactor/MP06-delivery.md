# MP06 家人提问、混合推荐与首页

对应 [#173](https://github.com/brycezhang/timenook/issues/173)。功能已实现；本票的 390px／320px 原生逐画板截图与完整点击验收仍待集成负责人串行执行，不将页面控制器和编译结果记作原生验收。API 与录音输入见 [MP06 契约](MP06-contract.md)。

## 可操作路径

- 故事书首页 → 家人提问 → 提出问题：仅文字，章节可不选；从章内进入时带入章节，仍可选「不选章节」。购买者没有成员关系时先填「你是主讲人的谁」，不从赠礼关系反推。主讲人沿用「本人」。编辑时展示并保留原作者、昵称和关系。
- 列表切换待回答／已回答／已跳过；详情可稍后、跳过、恢复、编辑、移除。开始回答先创建真实采访，将当前家人问题 ID 交给录音准备页；采访本身不算已答。故事保存完成后显示「回答故事」整卡入口。
- 无章回答保存为未归章故事，继续使用现有归章入口；有章问题完成后归入有效章。编辑已答问题的章节会移动故事；故事跨章移动也同步问题。移除问题不删除已有故事、原声和实际提问快照。
- 首页优先家人，按约两道家人题穿插一道大纲题；类内随机、本轮不重复，一类不足由另一类补齐。轮次重开保持本次稍后排除；显式恢复也不会让本次已稍后的题提前回流。重新进入故事书、切换账号／项目或小程序重新前台进入后可再推荐。已答与跳过不进入推荐池。
- 首页书名与封面整块进入书稿；故事数、照片数分别进入对应页面，零数量仍可点击；移除独立重复入口。问题与开始讲述同卡滚动。故事数仅计已有保存版本，照片数来自项目封存素材，原声按保存毫秒向下取整数分钟。
- 公开首页读取现有 offer，展示实际可购金额与不可购状态。用户项目只展示实际选定封面或书名封面，不用示例照片替代私人数据。
- 章节问题页同时显示大纲题与家人题，十个大纲题加一个家人题时显示十一题；作者来源与首页、列表、详情一致，家人题进入自己的详情，章内可直接提问。大纲排序继续只调整大纲题顺序。
