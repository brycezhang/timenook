# 设计参考图

71 张画板分别以 390×844 和 320×568 CSS 像素渲染，共 142 张。它们来自当前原画布的真实渲染器，供原生页面逐项对照；不是小程序运行或业务验收证据。画布批注标记仅在截图会话中隐藏，原文件和批注保留。

来源已同步登录同意确认、现行完整条款和 320px 首页标题换行修正；每份源文件与图片的 SHA-256 见 [manifest.json](manifest.json)。Main 窄屏图在标题修正后单独更新。

原生实测使用微信开发者工具的真实设备配置：iPhone 12/13 (Pro) 390×844，以及“录音布局 320×568”。设备切换后重新读取 `wx.getWindowInfo()`；不修改或模拟窗口宽度。微信系统状态栏、胶囊和系统弹窗另记，按实际内容区对照控件、字号、间距和交互。原生截图导出尺寸可能随开发者工具显示比例变化，逻辑宽度以运行时测量为准。

完整对应关系见 [design-map.json](../design-map.json)。其中原生截图与交互结果须由各票实际运行证据填写；参考图存在不代表该画板已验收。
