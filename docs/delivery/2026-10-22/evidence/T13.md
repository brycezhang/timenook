## 已实现边界

- `GET/POST /v1/projects/:id/plan` 读取/编辑已授权的当前个人计划。匿名、陌生人、仅付款或缺少有效 collection/sharing 授权均拒绝；讲述者有有效采集授权后可编辑，发起人还须获得有效共享授权。实际登录 session 以共享行锁参与事务，随后锁 Project、Subject；当前授权、绑定/epoch、协助期限和写入在同一事务，沿用 Participation 的规则与锁顺序。
- 原子 `expectedVersion` 追加同一份章节与问题计划；章节/问题可增删、改写、重排或清空，服务器保存真实作者。双角色竞争仅一个成功，另一方 409，不静默覆盖。计划历史与模板来源保持独立，照片和自由讲述起点保留；空白计划不成为后续起讲的设置前置条件。
- `POST /v1/projects/:id/plan/preferences` 使用独立偏好 expectedVersion。稍后回答、跳过、不适用、恢复可回答与禁问主题分别持久化。普通计划改写、移出章节/问题、清空计划不会写这些偏好。本人决定与显式重新启用保存 subject、真实 operator、方式和完整选择快照；协助决定还关联 T12 不可变当次会话证据。发起人普通编辑权限不能调用本人决定；必须提供同项目、同操作人、当前有效的最新 collection 会话，过期/旧会话/撤回后不能使用。
- 新迁移 `20261023140000_personal_plan_preferences` 增加本人偏好历史、实际提问快照及实际目录版本；已有迁移未改。偏好/目录版本由数据库阻止原地 UPDATE。实际问题快照保持不可变，回答关联只能从空写入一次、同值重放可恢复；不会因计划改写或章节移出而丢失。
- 真实小程序新增 `plan` 页，welcome 和 assisted 提供入口。实际 SessionClient/wx.request 支持章节/问题编辑与排序、本人回答状态、禁问与显式重新启用、清空计划；409 保留本地未保存修改并要求重新查询，不能自动覆盖。账号变化、离页、登录失效及协助期限到达时清除私人计划和草稿，迟到响应不能恢复。页面标明隔离合成状态；实际录音仍由 T14 接入。
- 按最新用户授权，窄改 Issue tracker 与交付 README 两处调度说明：ready frontier 独立票可以独立 worktree/分支并行，各自 TDD、相关检查、独立双轴和最终 PR CI；串行合并，每次合并后 main CI 全绿才进行下一票合并并放行依赖者；独立实施、PR CI 和审查仍可并行。没有修改 45 条依赖或真实完成口径。
