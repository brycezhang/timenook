## 实现

- `/app/` 为独立 Vite／TypeScript 应用，沿用小程序品牌配色；营销根路径保留自己的应用。
- 内测账号由私有 CLI 创建，登录链接 15 分钟、原子单次兑换；fragment 在页面加载后清除，兑换必须显式点击。明文凭据只写受保护输出文件。
- 网页使用受保护 Cookie、12 小时会话、来源／CSRF 校验；退出撤销相同 Session，现有用户 API 复用同一内部 User 和权限。
- 列表只显示当前账号获授权项目；删除或当前共享撤回后拒绝暴露项目内容。默认不配置即关闭。
- web-only 装配不启动旧期限后台扫描；非 test 中拒绝与尚未接通的新产品装配混用。主动权利和显式维护保持既有约束，完整真实运行仍须后续票据与长期服务改造接续。

## RED → GREEN 与相关验证

| 公开行为／检查 | 结果 |
| --- | --- |
| 登录链接加载后等待明确操作，清除地址票据且不写浏览器 storage | 首次因按钮缺失失败，实现后通过 |
| 登录服务未配置／不可用时给出提示并可重试 | 首次因无响应失败，实现后通过 |
| 同一标签页已有登录页时再次打开新 fragment 链接 | 浏览器检查发现无法进入；回归先失败，补 hashchange 后通过 |
| 真实 HTTPS 浏览器经 CLI 账号／票据进入 → 空项目列表 → 刷新恢复 → 退出 → 重进拒绝 | 通过，真实 PostgreSQL／Redis／Cookie，无身份网络替身 |
| 已使用和已撤销链接的真实浏览器兑换 | 通过，返回失败且不进入账号 |
| CLI／HTTP 认证、来源／CSRF、8 并发单次兑换、重启重放、限流、过期、跨账号隔离、启动维护门禁 | 后端 10 项通过；含既有 identity／AI／OSS 配置相关回归共 25 项通过 |
| API 生产构建／类型检查、网页构建／类型检查、既有前端类型检查 | 通过 |

浏览器命令为 `pnpm test:web`（5 项通过）；使用临时 HTTPS、独立 schema／Redis 前缀和隐私台账，CLI 输入与输出均在工作区外受保护临时目录，测试结束清理。自动截图、录屏、trace 关闭。开发入口在 IAB 检查了品牌、标题、主按钮和错误提示；浏览器检查不等同于真实手机、微信或云端结果。
