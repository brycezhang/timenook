# 将讲述者身份与登录账号分离

项目内的讲述者档案承载本人身份，微信账号代表登录操作人；讲述者绑定账号可为空。授权和确认同时保存主体、操作人、方式、告知/内容版本及证据，支持没有个人微信的讲述者由发起人同机协助。

付款不替代讲述者的采集、AI处理、共享及入书同意。动态关系和自定义称呼仅影响文案（模板范围按 ADR 0008 固定为一套）；双方编辑计划不改变本人拒答、确认和撤回权利。运营访问私人内容须关联限时授权与工单。

2026-10-30 交互收敛：开始页默认折叠资料使用详情。只有讲述者本人实际点击「确认并开始」时，才以一次事务记录采集保存、AI处理和向本项目发起人共享三项用途；访问、登录或查看详情不产生授权。不增设入书用途类别或单独入书说明步骤。

故事页阅读全文后只用「确认」按钮，按确定故事版本、内容 hash、当前告知和本次点击证据记录内容确认及入书决定，无需复选框或手写说明。已有明确拒绝或撤回不因简化交互自动扩大；调整决定仍由本人或有效当次协助操作明确提交。讲述者主体、实际操作人、三项用途记录和故事版本决定保持各自审计事实，同机协助身份及服务端版本校验不变。

同机证据形式、争议处理、无微信讲述者的导出/删除核验按D08确定。首版为一位成年讲述者本人参与、一位发起人的赠礼流程；其他主体场景须确定各自证据模型后开放。
