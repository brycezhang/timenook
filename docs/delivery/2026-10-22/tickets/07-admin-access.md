## 验收条件

- [ ] 管理员与小程序用户使用独立账号及会话，落实 MFA、HttpOnly/Secure Cookie、CSRF 和注销。
- [ ] 提供最小权限的受保护管理页与 API，匿名、小程序会话、缺权限和无效 CSRF 请求均被拒绝。
- [ ] 审计记录操作人、动作、请求标识及结果；日志不记录正文、会话令牌、云密钥或完整地址。
- [ ] 初始管理员通过受控命令建立，不内置生产默认口令；验证管理端登录/退出和服务重启后的会话规则。
