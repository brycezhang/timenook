# CI 修复与产品网页验收退出

2026-11-06 用户要求修复 CI 报错，并删除网页端 CI 验收项。

## 原因与变更

[失败运行 42174997245](https://github.com/brycezhang/timenook/actions/runs/42174997245) 的 `build`、四个 API 分片和营销官网均成功；两个 browser 分片失败，随后 `full` / `check` 被阻断。

`playwright.admin.config.mjs` 原来收集 `tests/admin/` 全目录，实际混入产品网页、浏览器模拟小程序和与旧产品流程耦合的跨端验收，共 26 个文件 / 106 个用例。失败涉及已退出产品的授权／确认接口、旧微信登录请求和已删除的 fixture 方法；这些旧流程不再作为当前产品的验收要求。

- 独立管理后台的登录、订单、用户管理测试移入 `tests/admin/console/`，原用例内容仅调整共用 helper 导入路径；CI 发现及分片汇总统一以该目录为准。
- 其余 23 个历史文件 / 92 个用例通过 `playwright.product.config.mjs` 手动收集，退出 CI，不修复或追认通过。`pnpm test:web` 改用该配置。
- 保留现有 browser 两分片及报告完整性门禁；没有删除后台独立验收、API 检查、生产构建或营销官网检查。
- 增加真实 Playwright 发现回归，验证 CI 只包含独立后台文件、两分片无遗漏或重复；同步原测试文件的文档链接。
