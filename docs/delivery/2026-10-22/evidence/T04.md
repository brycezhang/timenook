票据 [#5](https://github.com/brycezhang/timenook/issues/5)，实现基线 `221e9af67c6005e9e155cb2af411bf44aff83500`。2026-10-22 本地开发/合成测试完成，交付为 [PR #38](https://github.com/brycezhang/timenook/pull/38)；提交及修复结论见 [独立双轴审查](T04-review.md)，远端 CI 以 PR 最终提交为准。本票保持打开，D01 未冻结。

## 已实现与验证范围

- CLI 默认关闭、production 拒绝；输入只用于合成试验。原图逐字节保存，独立预览/印刷图记录 source hash。JPEG 八个 EXIF 方向以不同颜色象限独立验证，衍生图没有 EXIF/GPS；真实格式由解码器确定，改扩展名不改变判断。按实际 contain 占据矩形计算 DPI；300 DPI 为候选提示阈值，未变成商品规格。
- 真正 HEVC HEIC：仓库合成夹具 96×64、625 bytes，SHA-256 `d9046cf2a4f450fb4f5e53a6b4e78f8e08380889354c993ad4f1bda0e8895db1`。Sharp 0.34.5 / libvips 8.17.3 检查格式/尺寸，libheif-js 1.23.5 WASM 解码，独立源 RGB `(36,123,147)` 与输出每通道误差小于 8。没有以 JPEG 改名冒充 HEIC。当前拒绝多图、额外 EXIF 方位、ICC/HDR/非 8-bit HEIC；这些变体仍待候选样本验证。
- 固定官方 Noto Sans CJK SC Regular 2.004（OFL-1.1）、Playwright 1.58.2 / Chromium 145.0.7632.6、单个候选模板。长中文段落完整跨页，目录自身跨页时页码仍收敛；不收敛、字体缺 glyph、单块标题无法容纳均拒绝。图片 hash 被复核后嵌入，QR 在渲染前确定。
- PostgreSQL 007 保存随机稳定入口与封存原声的一对一映射。6 个并发创建、重试、API 重启返回同一入口；未封存 409，匿名/过期 401、外来身份与存储切换 404。鉴权逻辑沿用 T02，随机入口不是凭证。
- 从最终 PDF 每页 PNG 实际解码 QR，再经受控 HTTP 解析并下载对应合成 MP3；匿名读取拒绝，授权内容 hash 等于已封存原声。前缀剥离按 ADR 0009 在本地测试建模，未部署公网路由或真实小程序码。
- Vite 与 admin Vite 的 direct、`/@fs`、`?raw` 读取探针目录均拒绝，正常首页保持 200；这两条回归由主 Agent 独立完成并纳入最终全量。

## 审查修复：透明照片候选白底

独立 Spec 审查发现受支持的带 alpha PNG 在 JPEG 预览中透明区变黑，而固定白底 PDF 显示白色。以独立 RGBA 夹具先复现：全透明红 `[255,0,0,0]`、半透明红 `[255,0,0,128]`、不透明蓝 `[0,0,255,255]` 三个色区，公开 `photo` CLI 的预览白色断言失败，原始日志 `output/pdf/t04-logs/22-alpha-red.log`。

修复只在衍生像素编码前统一合成到候选模板白底 `#ffffff`；预览 JPEG 和印刷 PNG 使用同一背景，`photo.json` 记录 `candidateBackground`，原图字节及 hash 保留。候选背景不替代印厂纸张/色彩决定，迁移、HTTP 合同和依赖均未改变。

回归使用独立字面 RGB 期望 `[255,255,255]`、`[255,127,127]`、`[0,0,255]` 检查预览与印刷图；随后真正生成 PDF、独立渲染 PNG，以不透明蓝色块定位三个区域，再比较 PDF 像素与预览（每通道允许 JPEG 误差 3）。原图逐字节相等也通过。`22-alpha-green.log` 为 1/1 GREEN；修复后仅一次最终 `pnpm check` 的 `23-pnpm-check-alpha.log` 为 frontend 49 / API 79 / print 13，共 141/141、类型及全部构建通过。`24-alpha-cleanup.json` 读回 schema、Redis keys、public clips/entries 均为 0；没有重跑未受影响的 OpenAPI/native/admin-browser。

补充产物保存在 `output/pdf/t04-alpha-proof/`，`book/book.pdf` 共 3 页，SHA-256 `04520c51aa64f4ba2a5ab7843382e852a46120e07d11babce631d7bf55ad5b70`。实现 Agent 查看了 `pages/page-001.png` 至 `page-003.png`：封面、目录及色块页无裁切或重叠，透明区显示白色、半透明红显示粉色、蓝色保持不变。此前 7 页样书及其 hash 作为首轮已检查产物保留，不改写旧文件。
