# T12 · 支持无个人微信的同机协助与本人证据

GitHub：[#13](https://github.com/brycezhang/timenook/issues/13) · 状态以 GitHub 为准。
阶段：S1

## 交付结果

讲述者在场同意时，发起人可代操作录音；系统持续区分讲述者和操作人。

## 验收条件

- [ ] 协助会话绑定 subject、operator、用途、告知版本、当次证据及有效期，不创建假讲述者微信账号。
- [ ] 录音授权与故事/书稿确认分开，每次确认引用实际内容版本和独立证据。
- [ ] 会话过期、证据缺失或用途不符时拒绝操作；付款身份不能绕过检查。
- [ ] 小程序给出讲述者可理解的同意/拒绝路径；无微信讲述者能走既定客服核验渠道申请撤回和资料权利。
