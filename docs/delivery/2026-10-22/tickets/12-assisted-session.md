# T12 · 支持无个人微信的同机协助与本人证据

## 交付结果

讲述者在场同意时，发起人可代操作录音；系统持续区分讲述者和操作人。

## 验收条件

- [ ] 协助会话绑定 subject、operator、用途、告知版本、当次证据及有效期，不创建假讲述者微信账号。
- [ ] 录音授权与故事/书稿确认分开，每次确认引用实际内容版本和独立证据。
- [ ] 会话过期、证据缺失或用途不符时拒绝操作；付款身份不能绕过检查。
- [ ] 小程序给出讲述者可理解的同意/拒绝路径；无微信讲述者能走既定客服核验渠道申请撤回和资料权利。
- [ ] 无个人微信/协助参与沿 D08 核验流程产生同一幂等本人参与事件；长期服务不取消协助会话的安全有效期。后续本人换绑复用 T11 核验，逐次确认仍留独立证据，续期不能恢复已撤回或删除的权限。
- [ ] 同意/拒绝及证据过期状态符合[页面质量要求](../spec.md#质量目标与证据归属)；本票验证页面实现，目标用户双端试用统一由 T30 留证。

## 实现边界

沿用一套经 D08 确认的同机证据与客服替代流程；正常同意/拒绝保留小程序入口，争议人工核验，复用 T11 授权/换绑命令。
