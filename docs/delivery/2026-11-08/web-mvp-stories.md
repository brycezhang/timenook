# Vue 项目、故事与网页邀请（WV03）

已本地实现正式 Vue 的「选择项目 → 阅读/编辑故事 → 入书 → 项目与昵称管理」，以及网页邀请链接的生成、登录返回与明确接受。复用 ADR 0018/0019 的现行成员和版本规则，不恢复本人/双方确认、微信手动绑定或跨端跳转。

## 可操作范围

- `/app/projects/:projectId` 读取当前成员项目概览、真实故事计数与原声时长，支持长项目名称修改、搜索正文与标题、全部/已入书/未入书筛选。加载使用骨架，读取失败显示重试。
- `/app/projects/:projectId/stories/:storyId` 阅读真实故事，修改标题与段落并创建新版本；保持原故事的来源引用、照片和原声选择。编入/移出通过现有版本校验更新，编辑冲突显示明确提示并保留未保存正文，用户可读取新版本后再修改。
- 「我的」支持昵称修改，更新当前会话并通知其他标签重验，沿用同账号的小程序昵称。
- 购买者依现行 `canInvite` 生成有时效的网页链接；再次生成会使上一链接失效。复制失败时可直接选中链接复制。
- `/app/invite/:token` 为公开加入入口，微信聊天打开仍留在网页；未登录先通过短信登录，返回原邀请后勾选条款并明确接受。收到链接或仅登录不新增成员。接受后进入相同项目，成员可记录、编辑和成书；发起邀请资格沿用服务端现行判断。
- 私有请求先重验同一账号/会话，退出或跨标签账号变化会中止请求、清除页面资料，并丢弃迟到结果。另一标签成功登录时，当前登录弹窗自动关闭并回到原目的地。

录音、照片、原声播放、书稿和制作入口由后续切片补齐；本切片只接相应正式路由，不用假录音或假书稿填补。新实现没有新增后端业务接口；使用现有 Cookie/CSRF 桥接、成员、版本、幂等与条款契约。

## 本地验证

- 真实 PostgreSQL/Redis、隔离 schema/命名空间下，`tests/web-mvp/projects.test.mjs` 的 Chromium 与 WebKit 两条构建后 HTTPS 流程通过：成员项目读取、长名修改、故事搜索、阅读/保存、移出再编入、另一成员真实写入导致 409 且保留草稿、读取最新版本、昵称修改、邀请生成、短信登录回原邀请且不自动加入、明确条款接受、受邀成员编辑权和 320px 无横向溢出。运行时错误为零。
- 定向 API 回归 `project lists show…` 通过，同时验证购买名称、邀请公开名称、成员列表和改名一致。
- Vue 类型检查与正式构建通过；截图已查看手机故事阅读与电脑项目长名布局。
- `tests/web-mvp/entry.test.mjs` 的 Chromium 与 WebKit 均通过，复验跨标签页换号后原登录弹窗自动关闭并恢复目的地，旧恢复响应不能覆盖新账号。
- 浏览器夹具只在外部短信、微信、AI/对象存储输入使用隔离替身；应用 HTTP、数据库、Redis、队列、Cookie/CSRF、版本冲突及浏览器页面真实运行。夹具的短信登录等待真实发送结果后才读取测试供应商验证码，避免异步竞态。

执行入口：先构建 contracts、API 测试产物与 Vue，再用本机 `DATABASE_URL`/`REDIS_URL` 执行 `node --test --test-concurrency=1 --test-timeout=120000 tests/web-mvp/projects.test.mjs`。浏览器套件使用 4444 端口，不与同端口套件并行。

## 运行边界

本切片未部署、推送、发送真实短信、访问远端数据库或操作资金。真实微信内网页打开、真实短信到达、手机浏览器与小程序同号联用仍待部署后独立验收；浏览器引擎测试不代替真实设备验收。没有发布 GitHub 执行票。
