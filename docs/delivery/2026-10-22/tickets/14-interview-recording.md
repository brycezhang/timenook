# T14 · 接通分轮录音、本地恢复与云端封存

GitHub：[#15](https://github.com/brycezhang/timenook/issues/15) · 状态以 GitHub 为准。
阶段：S2

## 交付结果

讲述者从计划/自拟问题开始采访，录音可靠保存后可以离开、返回和按文件重试。

## 验收条件

- [ ] 实际问题保存文本、目的、计划版本及来源快照；client_clip_id 稳定，本地清单绑定账号/项目/采访，切账号不串素材。
- [ ] 复用 S0 验证参数，区分录音、本地持久保存、上传、校验、sealed；本地保存失败明确阻止虚报成功。
- [ ] 封存核验类型/时长/hash与最终对象，事务写资产/片段/额度及后续任务事件；跨项目关联由复合约束拒绝。
- [ ] 同键重放/异载荷/不同键并发只形成一个有效片段；复制成功落库失败可恢复，已封存前保留唯一的本地副本。
- [ ] 采访查询恢复已保存片段，后台/来电不自动重新开启麦克风；生产入口同时执行主体与用途授权。
- [ ] 新录音按 T10/D02 的制作期限、暂停及到期规则处理；到期前/恰好到期/到期后分别验证，已保存内容的恢复和资料保留按既定规则执行，不因制作到期静默删除。
- [ ] 录音页面符合[页面质量要求](../spec.md#质量目标与证据归属)，并提供从已绑定授权项目主页到开始录音的完整路径与计时；T19 复用入口，T30 做目标用户测量。

## 实现边界

复用 T02 录音控制、音频检查与私有封存；只补生产身份/项目/用途、额度、片段和任务事务。引用适用机制证据，验证真实产品录音入口和新增集成。
