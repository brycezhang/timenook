# 通用大纲与目录共用章节，实际问题和书稿保留快照

2026-11-11 用户明确默认大纲就是书稿目录。按 [ADR 0008](0008-single-builtin-template.md)，使用一套通用大纲，初始为六章、每章十题；与赠礼关系无关，内容围绕主讲人的第一人称经历展开。当前故事书的大纲与目录共用同一套章节，用户可增删、改名和排序，避免采访与成书维护两份不同结构。

创建项目时复制模板的确定版本，项目保留个人修改，模板更新不覆盖已有项目。问题可以增删修改、自由选择与跳过，不要求答满六十题；未回答问题不会成为书中空白故事。用户修改当前故事书不改通用模板。

内置问题及已选章节的家人问题回答后，故事归入对应章节。家人提问允许不选章节；其回答直接保存为普通故事，标记未归章，随时可归入任一章节，不再默认写入第一章。生成 PDF 只收录当前章节引用的故事，未归章不阻塞已有内容成书。移除问题或章节不删除已有录音和故事。

家人提问与大纲问题共用首页推荐池。进入故事书优先待回答家人问题，两类足量时按约 2 道家人题穿插 1 道大纲题，类内随机，本轮不重复。已回答、已跳过不推荐；稍后回答本次进入期间略过，再次进入可出现。家人问题保留作者及其相对主讲人的关系，首页、列表、详情和讲述页一致显示「关系 · 昵称的提问」，不从赠礼关系反推。

实际提问、素材来源与生成书稿分别保留快照；后续修改未来问题不改写已经发生的提问，修改章节和故事后重新生成 PDF，已提交制作版本不变。项目成员权限继续按 [ADR 0018](0018-project-members-and-simple-printing.md)，不恢复本人逐项确认门槛。

以上是本轮已确认的新产品规则，原画布当前为 71 张页面／状态、11 个分组，业务代码尚待更新。流程与实施差异见[需求整理](../../designs/timenook-modern-2026-11-10/project/REQUIREMENTS-2026-11-11.md)，具体题目见[六章六十题初稿](../../designs/timenook-modern-2026-11-10/project/OUTLINE-QUESTION-BANK.md)。
