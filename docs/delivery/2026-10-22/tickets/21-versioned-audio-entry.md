# T21 · 接通书中原声码与版本固定的受控回听

状态：approved（2026-10-22 用户调整后确认，待发布 GitHub）
阶段：S3

## 交付结果

读者扫描纸书入口，登录授权后只听到所印版本的原声；未授权者看不到私人信息。

## 验收条件

- [ ] 二维码只含随机稳定标识，入口与 book item 的有序音频清单固定，不指向最新稿、不包含姓名或访问凭据。
- [ ] 登录后每次解析/Range/下载重验身份、共享范围、期限、删除状态和 epoch；未知者响应不含标题/缩略图。
- [ ] 经鉴权网关下载临时文件后播放，退出/播放结束按策略清理缓存，不重定向到可分享 OSS URL。
- [ ] 真机验证扫码、登录恢复、切账号、已印后在线改稿与访问到期；纸书与历史导出副本的边界明确。

## 外部条件与完成边界

正式小程序路由/码生成能力与双端设备验证；模拟扫码不等于实物验收。

关闭前记录提交/PR、执行命令及结果、对应证据。只有本地适配器通过时写明“模拟已通过，真实验收待完成”，保持本票未关闭。凭据通过受限的 Git 忽略环境文件或平台密钥管理提供，不附在 issue 或日志中。
