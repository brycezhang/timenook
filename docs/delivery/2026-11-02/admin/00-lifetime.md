# 共用前提：长期服务与必要资料保留

GitHub：[#105](https://github.com/brycezhang/timenook/issues/105) · 保留 Parent #95，不复制建票。

## Parent

#95；该票同时是后台 #150 的共用前提，继续保留原父子和阻塞关系，不重复新建长期服务票。落实用户已确认的 ADR 0017。

## What to build

岁月成书的制作、回听、下载及必要资料长期有效。当前HTTP和Worker的期限扫描、服务资格判断与资料包清理仍使用旧有限期限；在接通网页真实链路前，直接按已确认新规则更新领域实现及夹具，移除过时期限配置及操作。

## Acceptance criteria

- [ ] 制作、回听、下载、导出申请及必要原声/转录/故事/照片/书稿PDF/完成资料包不因时间推进失效或清理；到达、超过2099-12-31同样成立，该日期仅用于必须填写日期的底层占位。
- [ ] 移除后台服务期限菜单/配置、暂停/恢复计时、到期审核和对应业务接口；套餐及用户页面不展示倒计时，仅删除已取消的期限操作；Vben 及三个业务入口由 #150 的子票交付。
- [ ] API定时器、Worker恢复、资料包和对象清理不再按业务期限删除必要资料；未封存、失败/未交付临时产物及无引用技术残留仍可按用途清理，不能误删唯一可用资料。
- [ ] 主动撤回/删除、独立拒绝台账、活动流停止、迟到任务拒绝、会话/上传/下载/客服授权安全有效期保持；长期资格与临时授权分别验证。
- [ ] 首本唯一权益、真实付款和退款/质量售后D07窗口、D06人工时限保持原规则，不新增权益或替代本人授权。
- [ ] 直接硬更新开发模型和合成夹具，不实现旧期限兼容、旧数据迁移、旧备份恢复、备份准备或回滚演练；旧期限测试不追认为新规则通过。
- [ ] 按公开HTTP/页面/维护入口逐行为RED→GREEN，真实PG/Redis验证；相关回归、类型、构建及独立双轴审查与最终PR/main CI通过。真实OSS生命周期与线上切换结果另记，未核对不能声称已完成。

## Source and scope

权威来源为用户已接受的 ADR 0017、#1 的长期服务决定及后台 #150 的长期服务条目。仅实施该决定所需的领域、契约、清理、界面期限移除与测试；工程完成后由网页和后台共同消费。默认不触达真实资金、私人录音或生产。
