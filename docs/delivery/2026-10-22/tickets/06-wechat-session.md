# T06 · 接通微信登录、会话与账号恢复

GitHub：[#7](https://github.com/brycezhang/timenook/issues/7) · 状态以 GitHub 为准。
阶段：S1

## 交付结果

小程序登录后使用服务端身份访问自己的资源，退出或会话失效时正确恢复；演示模式保留明确隔离。

## 验收条件

- [ ] 服务端用微信 code 换取身份，按 AppID/openid 唯一建立账号；不接受客户端自报 openid。
- [ ] 签发可撤销不透明会话，仅保存 token 摘要；过期、退出和不同账号访问有可观察的 401/403/404 行为。
- [ ] 小程序请求层使用统一契约，登录状态与本机演示资料分离，服务失败不自动回退到模拟购买成功。
- [ ] 通过 HTTP 边界测试会话重放、失效、跨账号和无效微信响应；真实双账号登录记录另行验收。

## 外部条件与完成边界

真实微信联调需正式 AppID/Secret 与合法域名；本地可用明确测试适配器，生产不能启用。

关闭前记录提交/PR、执行命令及结果、对应证据。只有本地适配器通过时写明“模拟已通过，真实验收待完成”，保持本票未关闭。凭据通过受限的 Git 忽略环境文件或平台密钥管理提供，不附在 issue 或日志中。
