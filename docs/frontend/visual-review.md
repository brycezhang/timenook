## 首屏文案对照

保留“送给重要的人，一本关于TA自己的书”“把散落的时光，变成一本温暖的书”“送给妈妈”“送给爸爸”“999元”“含1本实体书”等核心表达。未加入无依据的销售统计或额外宣传标签。

有意调整：对象收缩到妈妈/爸爸；删除“加印100元/本”“一个月内成书”和未冻结供应链承诺；价值文案按PRD改为“照片与声音一起珍藏”“把一生故事变成一本书”；补充“效果示意”和必要的演示状态。邀请页将长过程说明合并为说一段、确认、成书，并保留参与授权。上述调整来源于用户要求包含旧原型核心页面及现有MVP范围。
