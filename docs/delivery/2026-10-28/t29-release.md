# T29 普通商户装配与受控发布

2026-10-28，Refs [T29 #30](https://github.com/brycezhang/timenook/issues/30)。用户授权接入普通商户并部署，随后明确独立小程序尚未申请下来，AppID/Secret 留空。本页将工程装配、目标环境发布和正式验收分别记录；未完成的 T29/T30 条件继续保留。

## 本轮发布范围

普通商户配置由 `readConfig` 显式读取，商户私钥和证书必须匹配、有效；平台证书序列号与材料相符，或使用显式微信支付公钥 ID。真实模式只使用原生 HTTPS 传输，不接受测试替身，身份从 TimeNook 独立微信配置取得。支付与退款回调固定为独立域名下 `/api/v1/webhooks/wechat-pay/payments`、`refunds`，同一入口只剥离一次 `/api`。缺配置时回调返回 503，不能伪造已接收或入账。

管理页面改为 `/admin/`，管理 API、下载与 Secure/HttpOnly Cookie Path 为 `/api/v1/admin`。候选包同时包含 API/Worker、管理静态页、迁移、固定渲染资源和受审 `ops/` 模板。systemd API/Worker 使用独立进程组与资源限制；Worker 仅在真实转写/授权配置具备后启用，不用合成模式运行生产任务。模板不会自动启动服务或创建管理员。

正式商品和大纲尚未准入，普通商户装配不会把本地预览套餐转成销售。当前真实下单仍关闭。现有商户材料待启用、小程序身份留空，均不等于收款已启用或实际资金验收通过。

## 尚未满足的正式条件

- 独立小程序 AppID/Secret、合法域名、商户绑定、真实商品/大纲/商业政策和双端收退款；真实下单仍明确拒绝。
- 实际管理员、MFA 设备、密钥托管和恢复负责人；本轮不创建假管理员或代替本人完成 MFA。
- 当前 RDS 连接未启用 TLS，PostgreSQL SSLRequest 返回不可用；Tair 为明文 `redis:`，TLS6380 探测超时。Tair `volatile-lru` 不满足 `noeviction`；Lua、阻塞读取和令牌匹配的续租实测通过。未经跨应用变更评估不修改共享实例策略。
- 独立撤回/删除源的正式独立介质、密钥托管、防整体回滚与备份轮换；同机分目录不能证明这些成立。
- 正式 Worker/渲染分离、完整云端队列/供应商/积压/期限补扫、删除台账事件恢复、告警与业务 RTO/RPO。本地 T15/T26 的机制证据继续复用；空业务库的备份还原不能替代存在真实撤回/删除的完整恢复验收。

## 验证与回退方法

使用 CI 完整成功后产生的 Linux 候选，在新 release 目录解压并先验证 SHA256/manifest。目标机按锁文件安装依赖、生成目标 Prisma client，核验 native `fs-ext`；不把 Mac 的原生依赖上传。配置、旧 release 与路由备份分别保留。迁移前先制作独立受限数据库备份，停止本服务写入；迁移失败不切换。

Nginx 模板在目标机 `nginx -t` 通过后 reload；systemd 模板在目标机验证后只重启 TimeNook。验证公网 live/ready、管理 HTML 与实际静态资源、管理 API 未登录 401、空微信登录 503、支付/退款回调 503、文档拒绝访问，以及 legal-agent 原健康与三项服务。缺配置的 503 是如实关闭，不计为微信通知验收通过。

回退使用原 release、与其配对的环境及 Nginx/systemd 备份。数据库不能在仍有业务写入时盲目覆盖；已执行且不可逆的业务迁移不以切回代码冒充完整回滚。真实备份恢复在隔离目标验证；恢复私有业务前必须重放原独立源，并显式切换 authority。旧进程不能自动接管新目标。
