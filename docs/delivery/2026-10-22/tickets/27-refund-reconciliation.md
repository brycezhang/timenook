# T27 · 实现退款申请、金额预留与结果对账

GitHub：[#28](https://github.com/brycezhang/timenook/issues/28) · 状态以 GitHub 为准。
阶段：S4

## 交付结果

客服按已公示规则处理退款，超时或通知重放不会重复退钱，权益及生产状态保持一致。

## 验收条件

- [ ] 订单行锁下预留可退金额，成功和处理中金额合计不超实收；稳定退款单号，未知结果先查原退款。
- [ ] 通知验签解密核对订单/金额，持久化后与查单共用入账；覆盖同键重放、异载荷、不同键并发及回调遗漏。
- [ ] 全额终止、部分退款保留权益与质量赔付分别执行规则；批准时冻结新投产，交接未知先人工核验。
- [ ] 小程序显示实际金额/进度，管理端审计可追溯；退款不删除讲述者资料，真实收退款核验另留证。
