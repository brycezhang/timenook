# 前端设计依据

2026-10-19，用户确认采用 design/design-images/1.png–3.png 的新配色。图像中的文案与功能不是新增需求；流程依据 MVP PRD V0.5。采用原生 TypeScript / WXML / WXSS。

## 视觉约定

- 背景 #F8F4ED、纸面 #FFFCF7、墨色 #352D25、棕色 #986349、橄榄绿 #566348、弱文字 #817467、边线 #E8DED0。
- 标题使用系统宋体/衬线回退；正文使用系统中文无衬线。普通正文16–18px，讲述和故事正文20px，关键问题28px/1.5。按钮至少48px，主要按钮56–60px，录音116px。
- 首页保留品牌、赠礼主标题、亲情照片、妈妈/爸爸入口、三项价值和999元服务摘要。人物图片无额外滤镜。
- 邀请页保留收到礼物、大字邀请、信纸及三步过程。书稿保留大幅成书图、目录与原声/照片入口；印刷保留订单摘要、地址、固定底部操作。
- 语音页依据 Figma N03（3:259）实时设计上下文，沿用问题/提示/大按钮/底部换题结构，仅配色随用户新决定修改。
- 书籍与亲情照片为生成的效果示意，原始参考图不作为整页静态UI。

## 交互与范围

15个共用路由：首页、套餐、邀请、参与、项目、采访、故事、校对、成书、完整书稿、印刷、订单、我的、资料设置、服务。妈妈/爸爸共用实现。采访准备/录音/保存/追问为同一路由状态。

首本999元；不新增祖辈/任意对象、送礼场景、多个模板、加印或供应商时效承诺。支付/AI/印刷均明确为本地演示。真实麦克风通过微信 RecorderManager；浏览器预览使用 MediaRecorder。保存状态只称“本机保存”，不伪装已上传云端。故事的确认绑定版本，编辑使旧确认失效；印刷必须通过书稿内容与排版双确认。

## 素材

内置 imagegen 生成 family.jpg 和 book.jpg，参考1.png的亲情场景和3.png的实体书场景。提示词概要：暖色自然光、成年女儿拥抱母亲、奶油色毛衣和亚麻书；浅橡木桌上的米色精装书，书名“妈妈的一生”，植物与母亲肖像。两者不作为真实用户经历或实物打样证明。

## 2026-10-30 两端共用页面与任务聚焦

网页业务页直接渲染小程序 WXML / WXSS 并运行相同 Page 控制器；不维护第二套网页 UI。浏览器层仅适配会话、麦克风、文件、导航和原生操作菜单。网页登录、模拟支付及创建仍使用既定浏览器入口。

讲述页以 `design/review-2026-10-17/05-recording.png` 的问题、提示卡、大麦克风与底部换题为结构依据，沿用已确认纸面配色。首屏只有开始说和换个问题；点击大麦克风才确定本次问题并请求录音。录制时呈现计时、结束与暂停；停录后只聚焦选定片段的回听和提交。保存、转写状态自动更新，常规流程无需查询按钮；追问进入独立阶段，可回答、改写或直接整理。照片、自拟问题和其他片段由次级入口打开。

新讲述的草稿标识与服务端采访 ID 分开保存，恢复原讲述使用原 ID，刷新草稿使用当前账号/项目隔离的映射。故事页先呈现正文，再进行本人版本确认；文字修改、照片、原声和人工校对通过操作菜单进入。

故事版本仍有未处理核对项时，确认面板提供“先核对待确认事项”进入既有原生校对页，完成前禁用内容确认和允许入书，拒绝/撤回继续可操作；避免用户提交后才遇到版本冲突。

## 2026-10-30 同机协助用途选择

用户确认取消逐项同意/拒绝按钮，改为三项复选框及一个“同意所选并开始讲述”主按钮。首次默认全部勾选，可分别取消；已有拒绝、撤销或过期状态按服务端实际选择回显。点击前不提交授权。取消采集后主按钮改为“保存用途选择”，保存后留在当前页；采集同意且所有选择保存完成后进入新的讲述草稿。

仍为各用途分别记录选择与证据，使用既有接口和版本前置条件；未勾选项明确记录拒绝，部分失败不进入录音。授权明细、工单、导出/删除/撤回等收进“其他操作与本人权利”。故事与书稿的当次确认独立。网页适配标准 checkbox / checkbox-group，业务 UI 仅维护原生 WXML / WXSS / Page。
