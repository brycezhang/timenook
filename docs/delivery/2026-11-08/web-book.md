# Vue 书稿与书中原声

2026-11-08，WV06 本地实现；尚未部署。本阶段沿用 ADR 0018/0019 与已定书稿接口，不恢复确认、用途选择或预览运行器。

## 可操作的路径

- `/app/projects/:projectId/book` 读取当前项目的真实封面、目录、可入书故事及任务。书名修改同步项目名称；封面寄语、已有故事照片和不使用照片均保存到服务端版本。
- 章节可新增、重命名、排序、删除空章；故事可排序、跨章移动、移出目录和重新编排，显示当前故事版本并链接到正文编辑。
- 生成与失败重试调用真实书稿任务，按任务状态持续查询。未保存修改阻止生成；封面、目录或正文变化后旧稿显示需要重新生成。
- 当前就绪版本可直接阅读、下载经过长度及 SHA-256 核验的受保护 PDF。下载不会关闭已打开的阅读器。`?version=<书稿 UUID>` 固定展示该版快照，失效旧稿不能以当前版本或可下载文件冒充。
- 固定书稿的原声链接进入 `/app/audio/:entryId`，访问与播放前重新解析当前成员资格和该版录音清单，按原顺序读取受保护录音，提供真实播放器。
- PDF、封面图和原声均不写持久浏览器存储；离页、退出、账号变化、访问截止或权限拒绝时停止媒体并撤销临时地址。原声页隐藏时停止播放。
- 就绪书稿链接到独立 WV08 的 `/app/projects/:projectId/production`。

## 验证

公开 HTTP、真实 PostgreSQL/Redis、Worker 与构建后 HTTPS 浏览器为本次既定验证边界，外部短信、微信、ASR/AI 和对象存储使用隔离夹具，输入为明确合成素材。

- Vue 类型检查和生产构建通过。
- 定向浏览器覆盖真实封面照片与无照片保存、书名/寄语、目录跨章、真实 PDF 生成与下载、固定旧版本、原声播放、跨标签退出清理、成员同时修改后的冲突保留，以及 320px 无横向溢出；截图位于本地 `output/playwright/web-book-{mobile,desktop}.png`。
- 浏览器发现并修复显式刷新时仍可编辑的竞态：刷新保留内容并禁用操作；本地修改继续使用原来的封面、目录、项目版本基线，后台查询不能扩大保存所接受的版本。

真实云存储/供应商、服务器发布、手机 Safari/Android、纸书二维码、实际印刷和实物交付由整体集成与运行验收另行记录；本次不替代这些证据。
