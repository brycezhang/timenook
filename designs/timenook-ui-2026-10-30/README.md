## 怎么评审

顶部切换桌面网页／手机网页／微信小程序。左侧（手机在顶部）跳转 19 个页面／状态，也可以跟随产品内的主操作点击。身份选项只是评审控制，不是产品中的越权切换功能。

建议路径：项目 → 选题 → 准备 → 本人资料用途选择 → 录音／暂停 → 回听 → 提交 → 处理 → 可选追问或整理 → 故事校对 → 一键确认故事 → 生成新书稿 → 同版双方确认 → 发起人示例地址 → 制作条件摘要。使用“重置体验”清空内存示例。

- 录音、回听和处理是明确标注的交互示意；不会获取麦克风或播放真人声音。
- 不保存任何真实个人信息，不创建项目、工单、授权、订单或制作申请。地址请用虚构信息。
- 当前原型展示核心流程与次级入口结构；复杂售后、导出、删除、目录、照片编辑等仅到弹层或梳理层级，完整状态见实施清单。
- 小程序视图不绘制虚假系统状态栏／微信胶囊；后续原生实现使用真实平台导航。
- 本轮未更新业务源码、GitHub Issues 或部署。

## 第二轮调整

- 故事确认只保留「确认」，去掉复选框与手填说明；按当前入书用途记录本版决定。正式前端与操作证据适配仍属后续实现。
- 选题的主、次操作上下分行，12px 间隔，主按钮占整行。
- 保存／文字处理改为状态卡，与现有上传、封存、任务查询状态对应；不显示百分比、预计时间，不再按时间自动完成。请用评审栏“处理状态”切换各状态。
- 首版查看 `index-v1.html`；当前 `index.html` 为反馈后版本。

## 第三轮调整

资料用途页改为简短说明、默认折叠的详情与「确认并开始」按钮，移除四组同意／不同意选项。点击一次后记录四项用途同意并进入录音准备；仅打开页面不会改变用途状态。第二轮存档为 `index-v2.html`。
