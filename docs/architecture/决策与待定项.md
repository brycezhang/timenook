# 架构决策与上线参数

版本：V1.0 · 2026年10月20日 · 定稿。本文列出目标架构的固定决策及上线前必须冻结的业务、工程参数；实现状态见[前端说明](../frontend/README.md)。

## 1. 架构决策

| 编号 | 主题           | 决策                                                   | 实施依据与边界                                                          |
| ---- | -------------- | ------------------------------------------------------ | ----------------------------------------------------------------------- |
| T01  | 后端           | TypeScript / NestJS + Fastify                          | 对齐wutong-admin，REST与OpenAPI                                         |
| T02  | 部署形态       | 模块化单体，API/业务Worker/渲染器分进程                | [ADR 0001](../adr/0001-modular-monolith.md)；业务事实同库               |
| T03  | 客户端与管理端 | 原生微信小程序、Vben Admin web-antd                    | 目标服务端和管理端需实现                                                |
| T04  | 数据与调度     | RDS PostgreSQL / Prisma，Tair / BullMQ / ioredis       | RDS持久化任务与Outbox；Tair兼容性按S0验证                               |
| T05  | 版本与交付     | 故事/计划/书稿快照，版本确认及生产文件hash             | [ADR 0002](../adr/0002-versioned-publication.md)                        |
| T06  | 身份与授权     | 讲述者、操作账号与同意证据分别记录                     | [ADR 0003](../adr/0003-subject-consent.md)；关系不授予权限              |
| T07  | 基础云服务     | 阿里云ECS、RDS PostgreSQL、Tair与私有OSS               | [ADR 0007](../adr/0007-aliyun-and-wutong-stack.md)；地域/规格开通时冻结 |
| T08  | AI服务         | 文件ASR首选豆包，文本模型首选DeepSeek官方API           | 固定资源/API/模型配置，按D03/D08核对处理条款；无自动跨供应商回退        |
| T09  | PDF            | 固定模板 + Playwright / Chromium                       | 固定渲染与字体环境，真实打样后定规格                                    |
| T10  | 工程与发布     | pnpm workspace，ECS/Nginx/systemd release包            | Node、依赖、Prisma运行目标及锁文件在初始化时验证                        |
| T11  | 范围           | 以分轮采访和首本交付为核心                             | 自主Agent、RAG、向量库、多人协作、加印及自动供应链不纳入MVP             |
| T12  | 赠礼关系       | 可配置类型与项目自定义称呼                             | 订单保存关系快照；一位讲述者、一位发起人                                |
| T13  | 录音处理       | 录音 → 可靠保存 → 文件转写 → 可选追问 → 故事确认       | [ADR 0006](../adr/0006-file-asr-after-save.md)；等待可离开并恢复        |
| T14  | 大纲与问题     | 内置模板复制为个人计划，双方可编辑，本人决定回答和入书 | [ADR 0005](../adr/0005-personal-interview-plan.md)                      |
| T15  | 工程基线       | 参考wutong-admin的NestJS/Vben工程                      | [源码依据](wutong技术栈对齐.md)；TimeNook独立数据与凭据                 |

## 2. 上线前必须确定的参数

| 优先级 | 决策             | 具体输出                                                                                                                               | 最晚节点                                                 |
| ------ | ---------------- | -------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| P0     | D08 授权与准入   | 主体、微信类目、实际数字制作+实体书商品的支付路径及双端可用性、发货管理要求；同机证据与争议流程；无微信讲述者核验/交付；模型与印厂准入 | 真实采集、支付及付费试点前                               |
| P0     | D01 实体书规格   | 尺寸、纸张/装帧、色彩、页数、出血、文件格式、字体许可及照片清晰度阈值                                                                  | 正式模板及套餐发布前                                     |
| P0     | D02 制作权益     | 时长、起算点、暂停/未开始及到期处理                                                                                                    | 售卖前                                                   |
| P0     | D03 资料服务     | 回听、资料保留、原图/采集原声与必要衍生图/音频、导出、活动数据/历史对象/备份/供应商副本期限                                            | 采集/售卖前                                              |
| P0     | D04 额度与成本   | 单段/总录音、照片、整理/主动重生成、追问次数与超额规则；ASR调用/轮询额度与系统重试预算分开                                             | 售卖前；技术试验值不冒充权益                             |
| P0     | D07 退款         | 未参与、已使用、已投产及质量问题金额/时限/权益处理                                                                                     | 售卖前                                                   |
| P1     | D05 配送         | 包邮/不支持地区、核验方式                                                                                                              | 售卖前，支付前告知                                       |
| P1     | D06 人工时限     | 校对、导出、生产、物流、客服SLA与负责人                                                                                                | 售卖前                                                   |
| P1     | D09 内容方案     | 首批原创/授权模板与问题、审校负责人、禁问分类、内容试用及质量阈值；推荐3次/转录就绪后追问5秒仅为待测建议                               | 模板发布和用户试用前                                     |
| P1     | D10 关系场景准入 | 首批类型目录、自定义文案限制；本人自购、未成年人、逝者纪念和多主人公是否后续支持及各自证据模型                                         | 开放对应场景前；首版为成年人本人讲述、发起人与讲述者分离 |

工程参数须冻结：阿里云账号/区域/VPC、ECS规格、RDS版本/高可用/备份、Tair版本/架构/队列策略、OSS Bucket/角色/生命周期；豆包服务资源/鉴权/模型与API配置；DeepSeek具体模型/上下文/预算/处理条款。凭据只保存在服务端，TimeNook各环境独立配置。

P1表示决策排序，相关参数仍须在对应节点前完成。999元一项目一本的完整销售参数发布为不可变package_version；必要参数缺失不开售，改价或改期不追溯更改已售订单。

## 3. 发布前验证

| 验证              | 方法                                                                           | 通过要求                                                                    |
| ----------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| 微信录音与保存    | iOS/Android目标机：格式、停止文件、权限、来电/后台/锁屏/强杀/断网              | 清楚区分本地与云端保存；仅承诺已实际保存片段的恢复                          |
| 文件ASR与任务恢复 | 豆包提交/查询、签名与STS到期、未知提交结果、重复结果、队列丢失、撤回后迟到结果 | 复用原声和逻辑任务，无重复扣额或覆盖新稿；跨云取源可用且权限受限            |
| 图片与受控读取    | 原图/预览/印刷图、HEIC/方位/低清、暂存权限、音频/PDF/缩略图及缓存              | 私有读取与封存校验有效，撤回后停止访问                                      |
| 商品与支付        | 实际主体准入、双端支付、未知下单结果、通知重放/查单/退款/发货管理              | 真实核验后幂等激活，退款金额与权益一致                                      |
| 关系与个人计划    | 新类型、称呼、停用；双角色冲突、模板更新、跳过/拒答/禁问                       | 不覆盖个人内容，不把关系当经历标签                                          |
| AI质量            | 经授权样本覆盖口音、停顿、模糊/矛盾、拒答及不适用经历                          | 豆包转录与原声可核对；DeepSeek追问中性且有来源，不编造事实                  |
| 时延与成本        | 短片段保存至出稿总耗时、排队、失败/重试、跨云流量和人工                        | ≤5分钟输入P95出稿≤3分钟为内部试点目标；未终态持续显示处理中；以真实账单校核 |
| PDF与恢复         | 完整内容、目录、照片、二维码打样；撤回、备份恢复、可读导出                     | 生产文件与确认hash一致，失败版禁止投产                                      |

验收与实施阶段的对应关系见[交付与运维](交付与运维.md)。
