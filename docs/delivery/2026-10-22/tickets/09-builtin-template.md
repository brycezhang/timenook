# T09 · 后端内置单套默认大纲并复制为个人计划

状态：approved（2026-10-22 用户调整后确认，待发布 GitHub）
阶段：S1

## 交付结果

后端维护一套固定、中性的大纲与问题，创建项目时按模板版本复制为独立个人计划；用户无需先选模板即可开始。

## 验收条件

- [ ] 默认章节/问题/目的以服务端代码常量维护，有稳定模板标识、版本和内容 hash；幂等初始化不可修改已存在的同版本内容。
- [ ] 默认起点不预设婚育或职业经历，保留照片/自由讲述；具体文案按 D09 原创/授权审校，未审校样本明确仅供测试。
- [ ] 新项目固定引用当时的默认模板版本并复制计划；代码更新模板版本后，旧项目内容、个人修改与禁问偏好不改变。
- [ ] MVP 不提供运营模板 CRUD/发布页面，也不提供多模板选择/推荐/切换；双方仍可修改自己的章节与问题。
- [ ] 通过公开 API/项目创建边界验证默认起点、重复初始化、模板版本变更及项目隔离。

## 外部条件与完成边界

正式默认文案由内容负责人按 D09 审校；代码内置不等于取消内容质量验收。研发可先使用自拟合成文本。

关闭前记录提交/PR、执行命令及结果、对应证据。凭据与私人样本不进入 Git、issue 或日志。
