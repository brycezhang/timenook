# T30 负责人确认清单

日期：2026-10-29。用于[验收准备](t30-acceptance-preparation.md)的人工输入收集。以下空白项均为**待确认**，不因文档提交而冻结。已知的产品决定不重复提问：999 元、一个项目、一位成年讲述者、一位独立发起人、一本首本实体书及约定运费，完整导出不另收费；本人自购、未成年人、逝者纪念、付费加印/超页不在首版范围。

## 优先回复的四组事项

可先回复安排和已有材料位置，暂时没有的保留“待定”。私人素材、完整地址、身份证明和凭据经受限文件/证据库交接；聊天和 Git 只记录脱敏引用。

| 顺序 | 需要你确认 | 回复格式 | 随后由工程/运营完成 |
| --- | --- | --- | --- |
| 1 | 内部项目与样本：哪一位成年讲述者、哪一位发起人；是否需覆盖无微信同机协助；iOS/Android 设备及操作人是否可安排；是否已有获授权样本 | 人员用代号；参与/设备可用时间；授权材料引用或“尚未准备” | 按覆盖情况拟定试验规模、口音/网络分布、告知与协助方式；预登记后再采集和测量 |
| 2 | 印厂与书籍：是否已有供应商/联系人、正式规格、报价、周期及打样安排 | 受限供应商记录引用；已有/待询价；规格和报价材料引用 | 按 D01 核对文件要求、成本和回执；形成校样/实物检查表。实际询价联系、打样支出和生产交接另按授权范围执行 |

## 用户试验与质量决定

执行前由实际负责人填写以下内容，空白不作为已批准的试验计划：

| 要决定的内容 | 待填写 |
| --- | --- |
| 内部项目双方、目标讲述者及是否需同机协助 | 代号/受限引用、可用时间、具体授权范围 |
| 样本规模与覆盖 | 总样本数；口音/年龄段/熟练度；iOS/Android 设备；正常/弱网；照片格式；每组数量 |
| 预先排除规则及观察截止时间 | 输入总时长不超过 5 分钟的评测范围；事前排除理由；失败、接管、未终态全部保留 |
| 内容审校与计时记录人 | 具体负责人、复核方式和原始记录位置 |
| 缺陷处置与重测 | 谁修复、何时重测、哪些变化使旧证据不再适用 |
| 目标调整及试点决定人 | 未达内部质量目标时，保留原指标/差距/整改或明确调整决定，再决定试点 |

既定目标沿[父规格](../2026-10-22/spec.md#质量目标与证据归属)：目标讲述者从已绑定授权项目主页到开录不超过 60 秒；总输入不超过 5 分钟的样本至少 95% 在 3 分钟内成功出稿。本文不另定样本数、质量阈值或销售承诺。

## 决定怎样生效

每项决定需记录实际负责人、真实决定时间、适用政策/规格版本及 `record:` 受限证据引用，并回填原责任票。D02–D08 的实际副本按 T05 说明放 Git 忽略的受限目录，程序校验结构后还需人工核实证据真实性。实现不能准确表达实际选择时，先补契约/装配及验证，再执行验收；不拿相近枚举代替真实决定。

真实招募/售卖、资金、供应商与生产操作分别按实际范围取得授权。T30 的准备包、文档 CI、负责人填写问卷或参数完整性通过，均不等于 T30 放行。
