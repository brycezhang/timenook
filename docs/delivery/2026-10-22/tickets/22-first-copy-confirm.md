# T22 · 双方确认同一 PDF 并唯一预留首本制作

状态：draft-review（待确认拆分，尚未发布到 GitHub）
阶段：S3

## 交付结果

讲述者确认内容，发起人确认完整 PDF 与地址后，提交首本且无需再次付款。

## 验收条件

- [ ] 双方确认绑定同一 book version/snapshot hash/PDF hash，发起人另绑定地址 hash；内容或地址变化使对应确认失效。
- [ ] 事务检查真实付款、权益、当前书稿、全部故事许可、授权/删除/退款冻结、生产规格及双方确认。
- [ ] 同键重复返回原生产单，异载荷冲突；不同键并发仍只预留同一权益和首本生产单，管理端审核不能绕过。
- [ ] 页面显示已付999元、制作1本、本次无需支付及约定配送信息；未确认/旧版/超规格均阻止提交。
