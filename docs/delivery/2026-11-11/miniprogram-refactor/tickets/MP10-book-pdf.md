# MP10 · 封面编辑、真实 PDF 与扫码回听

状态：ready-for-agent；GitHub [#176](https://github.com/brycezhang/timenook/issues/176)，父规格 [#166](https://github.com/brycezhang/timenook/issues/166)。父规格：[小程序全量重构](../spec.md)。

## 交付结果

用户编辑并保存封面，生成只含已归章内容的真实 PDF，在系统查看器打开，并通过书中二维码回听固定版本原声。

对应差异：F16、F17。主责画板：`BookEmpty`、`BookOverview`、`BookCover`、`BookReader`、`PdfDocument`、`BookChanged`、`BookGenerateFailed`、`ReaderFailed`、`OriginalAudio`。详见[画板对照表](../DESIGN-MAP.md)。

## 验收条件

- [ ] 封面书名、寄语和照片是同次草稿；选图返回继续编辑，保存才生效，直接返回放弃未保存修改。
- [ ] 空稿、生成中/失败、已就绪、待更新与打开失败均有对应状态；只有当前就绪稿可预览/制作。
- [ ] PDF 只按统一章节及故事顺序生成；未归章不阻断已有内容，不默认全收录，空章/未答题不进入正文。
- [ ] 系统查看器打开真实 PDF，目录只读，不新建自定义翻页器或 PDF 内播放器；系统 chrome 与设计内容示意分开验收。
- [ ] 二维码对应固定版本原声，登录和权限核验后播放；退出/无权限不可听，改稿不改变旧书原声。
- [ ] 本票全部主责画板完成设计与原生 UI、交互对照，记录 390px/320px、真实入口、截图与差异处理；不留死入口或用样例数据冒充业务。
- [ ] 实现、相关检查、原生验证及外部待验分别记录，改动与测试只覆盖本票实际边界。

## 数据与契约边界

本票按新方案直接修改相关前后端、共享契约和数据库。开发数据可破坏性重建，不做旧模型兼容、双写或旧接口别名。影响现有网页/后台消费者时同步适配，不扩展视觉范围。

## 测试决策

真实 PDF 生成/页数/收录内容/版本 hash 和原声授权集成测试；原生取消/保存封面、生成/打开/失败恢复、扫码进入回听。

复用现有测试入口，优先验证公开行为；数据库约束使用真实 PostgreSQL/Redis。外部待验不视为功能缺失，已实现能力与未验环境分别说明。
