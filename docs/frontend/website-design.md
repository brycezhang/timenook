# 官网视觉与交互依据

本次沿用已确认的小程序视觉与现有素材。布局参考保存在 [完整页面布局](../../design/website/layout-concept.png)，以[营销需求](marketing-requirements.md)中的功能、素材和版权为准。

## 设计系统

背景 #F8F4ED，纸面 #FFFCF7，正文 #352D25，标题 #593B2C，点缀 #986349，主按钮 #566348，边线 #E8DED0。标题使用系统宋体/衬线，正文与控件使用系统中文无衬线。正文 16–18px，桌面主标题约 64px，手机约 38px。内容宽度 1120px，左右留白在手机缩为 22px。按钮不少于 48px，主按钮为圆角胶囊；主要图片区采用小圆角，无颜色蒙层。

## 对布局参考的明确修正

- 参考图中的装饰花枝、内页老屋图片并非现有素材，首版不采用；样书用真实 HTML 文字呈现既有演示故事。
- 参考图中的播放与波形不属于本次已确认交互，首版改为「示例讲述／整理后的故事」文字切换，不模拟音频。
- Logo 完整使用用户原图，保留原图文字与背景；页面公司名称使用已核对的版权主体。
- 当前下单按钮打开「小程序即将上线」提示，关闭后恢复焦点；不生成小程序码，不表示真实付款已可用。

以上修正来自已确认业务范围与素材要求，生成布局中的新增内容不构成产品需求。视觉验收分别核对首屏层级、配色、宋体标题、图片区、书稿阅读、套餐区与手机排版。
