# T16 · 接通照片起讲与私有照片处理

GitHub：[#17](https://github.com/brycezhang/timenook/issues/17) · 状态以 GitHub 为准。
阶段：S2

## 交付结果

用户可以先选照片讲述或事后补图，每张照片独立保存、重试并关联正确故事。

## 验收条件

- [ ] 照片复用上传会话/封存规则，多图逐个展示进度，延迟完成与切项目不串图。
- [ ] 分别记录原图及处理版本/父子资产；应用方位并清理衍生图非必要 EXIF，控制像素/内存，低清只提示不编造图像。
- [ ] 预览/缩略图/印刷图均受权限约束；格式不支持时给出可恢复提示，不以预览图覆盖原图。
- [ ] 补图、裁切、说明或排序产生新素材引用快照；与故事确认的失效规则由版本用例执行，已保存录音无需重录。

## 实现边界

复用 T04 图片处理与 T14 生产上传封存，增加照片起讲及版本关联；仅支持已验证格式/参数，特殊裁切可受控人工处理后重新确认，不做图片编辑平台。
