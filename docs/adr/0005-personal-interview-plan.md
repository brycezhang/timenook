# 模板复制为个人采访计划，实际问题与书稿分别保存快照

内置大纲发布不可变模板版本，复制为独立项目计划；发起人与讲述者均可编辑章节、问题和顺序，讲述者决定回答、跳过、禁问和入书。关系类型仅用于模板推荐，不预设人生经历或授予权限。

项目保留个人修改，模板更新不覆盖现有计划。实际显示的问题、素材来源与交付书稿分别保存快照；采访计划不要求答完，也不直接等同最终目录。

修改未来问题不触发故事重确认或转写；实际目录与内容变化按受影响版本重新确认。具体模板、问题及追问参数按D09完成审校与试用。

详见[大纲与追问设计](../architecture/大纲与追问设计.md)。
