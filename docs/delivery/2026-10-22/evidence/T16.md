## 已实现公开行为

照片 HTTP 位于 `/v1/projects/:projectId/interviews/:interviewId/photos`。创建意图固定稳定 `clientPhotoId`、实际采访/问题/主体/操作人、binding/epoch、存储域及 bytes/hash。原订单冻结 D04 的 photos/count 在 project 锁内预留一张；不同 HTTP key 并发同稳定 ID 归并，同 key 异命令或稳定 ID 异载荷 409。`upload` 精确授予单对象/长度，`status` 恢复同意图，`release` 幂等取消未封存预留且保留原文件。collection-only 同机协助通过 `context` 仅恢复当前 actor 的素材状态，不获得私有历史或图片读取。

`seal` 读取实际暂存字节、测格式/像素、应用方位并写独立 original/preview/print 资产，记录实际 hash/bytes/MIME/尺寸、父资产与处理版本。预览实际缩到最大 1200px，资产尺寸对应实际产物。缩略入口明确复用受控 preview。JPEG/PNG/已验证候选 HEIC 沿同一 T04 内核；其原 Probe wrapper/开关和 scope 保留隔离。Unsupported/损坏/超限返回可恢复拒绝，不报 sealed、不替换原图；可取消预留后另选支持的原文件。

新增运行依赖仅 API package 的固定 Sharp 0.34.5、libheif-js 1.23.5，lock 只追加该 importer。像素内核和有界进程运行文件随 API package 交付；已使用 `pnpm --filter @timenook/api deploy --legacy --prod` 的独立产物实际执行 HEIC、方位 JPEG 和 1200px 预览。API 进程最多同时处理 2 个图片任务，同 adapter/同输入共用 in-flight 结果，忙时 503；持久意图/资产/快照仍由 PostgreSQL 恢复，不以该内存优化代替持久事务。单任务保持 16MiB 源字节、1600 万像素、15s、128MiB heap、384MiB sampled process-tree RSS；RSS 采样不是 OS/cgroup 硬隔离。

对象 I/O 后在最终写入事务复核当前 session、subject/operator、collection、binding/epoch、协助时限与制作资格。原图、所有衍生图和素材引用/用量在一个事务写成；复制完成而数据库回滚保持 pending，同意图重启/并发恢复只形成一次资产、快照和消费。提交未知结果不盲删 final。素材关系以真实 PostgreSQL 复合 FK 限定 project/interview/photo、同照片父子资产及引用，不仅靠 JSON/if；资产/快照/引用更新被 immutable trigger 拒绝。

素材 `materials` 以 expectedRevision 追加不可变有序引用，冻结实际资产 ID/hash/处理版本及说明。补图封存、说明、排序均创建新快照；同 command key 的修改响应丢失后，即使已有后续版本，仍返回其精确不可变结果。受限 `crop` HTTP 仅允许当前本人/有效协助对其真实原图做有边界整数矩形裁切；服务端读取原资产，不接受客户端 storageKey/parent/hash，生成新子资产与新快照，原图/旧快照不变。没有自由图片编辑 UI、生成式补清晰度或确认接口。

所有内容入口执行当前共享权限及实际 asset.kind 对应的 D03 originalPhotos/derivedPhotos，I/O 后再复核；包括 asset-ID 读取，不能借 print 参数绕过原图期限。图片响应为 `private, no-store`、nosniff，客户端不获得公开 OSS 内容 URL。制作到期不等于资料删除。默认没有照片路由；synthetic 照片装配仅 test + 已隔离 recording/participation + 显式候选 placement，production 拒绝。

真实 interview 的“看着照片讲一讲”进入新照片 Page；已有采访可事后补图。wx.chooseMedia 显式请求 original，但是否取得设备相册原文件仍待真机验证。每张照片独立保存文件/hash/清单、上传/校验/封存与失败重试；清单失败重试复用同 savedPath。清单按 deployment/AppID/稳定账号/project/interview 分区，迟到保存保留原归属，上传成功与失败响应均受页面/session fence 约束。单图失败不阻断其他照片，切项目/账号不串图，同账号可恢复。未封存唯一原件不删除。

说明草稿固定原 revision，上传完成不悄悄推进其 base；409 保留草稿，明确放弃后才刷新。迟到修改响应不能将页面快照倒退。离页/401/403 清私有视图；旧项目迟到 403 不清掉新项目。受控预览经 bearer 下载并复核实际 hash/bytes，登记与直接路径清理覆盖登记失败/迟到下载/并发预览；迟到旧图只删自己，当前图在离页时清理。
