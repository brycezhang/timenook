# 网页与小程序界面、完整入口流程

日期：2026-10-30。对应 #95 / #98 / #101 的体验修复；已定方案、工程验证与部署记录分别列出。

## 用户确认与实现

网页沿用小程序的纸面配色、宋体标题、橄榄绿主按钮、图标导航、故事列表与单题录音。共用 WXML / WXSS 和页面控制器同时调整；参考 `design/design-images/1.png–3.png`，效果图中的加印、假页数、配送时效等未确认功能不进入实现。

用户补充要求：保留正常登录、套餐选择和支付流程；内测中点击登录直接进入内测账号，点击模拟支付后进入填写主人公及书名、创建项目。官网四个制作入口现在直接通往 `/app/`。

- 点击“微信登录”建立当前浏览器独立的内测账号；再次登录可继续使用该账号，不共用他人的资料。现有私发登录链接仍可使用。
- 套餐页选择妈妈、爸爸或自定义称呼，勾选说明后进入支付确认；可取消。模拟支付成功后进入创建页，刷新可继续填写；提交创建真实 `internal-acceptance` 项目。
- 模拟支付不创建真实付款、交易或首本生产权益；项目仍 `physicalProduction=false`。仅显式内部验收模式且未配置支付时提供 mock 接口，常规模式拒绝。
- Cookie、Origin、CSRF、账号隔离和服务端项目创建锁继续生效。同一创建请求并发或重试返回同一项目。登录与支付的替身不代替本人用途授权、故事或书稿确认。
- 项目页根据状态呈现邀请、同机协助、本人用途选择或开始讲述，附可恢复讲述、故事列表、真实处理状态和底部导航。未授权时提供可操作的下一步。
- 修复网页表单每输入一字即失焦的问题，保留光标/选区，中文组合输入结束前不替换表单节点；大纲、故事、追问等共用表单均使用此行为。
- 修复邀请页返回项目、讲述者从“我的”进入用途选择、网页分享按钮无响应；支持原生 Web Share，未提供时复制链接。
- 成书页区分装帧效果示意与实际确定书稿。已生成版继续读取同版封面、目录、节选、页数和 PDF，不用示意图替代实际内容。

## 工程验证

浏览器插件未提供，采用仓库现有 Playwright Chromium 工作流。新完整入口用独立 PostgreSQL schema、Redis 前缀和两个独立浏览器上下文，API 与授权为真实本地服务；与已有录音封存用例分别覆盖。

已检查参考配色、衬线标题、正文层级、纸面留白、按钮尺寸、图标导航与首屏主操作。登录和套餐的 Web 专用界面使用相同视觉变量；业务页两端复用源码。390×844 手机与1280×900桌面已截图；官网另覆盖320、390与1440宽度。截图、会话与临时脚本保留在 Git 外 `/tmp/timenook-web-ux/`。

验证结果：`pnpm test:web` 22/22、`pnpm test:website` 18/18、`pnpm test:frontend` 393/393；真实 PostgreSQL/Redis 的网页项目、mock 入口和参与授权定向回归21/21。网页、前端类型检查、contracts/API测试编译、API/网页/小程序预览/官网构建通过；官方 wcc/wcsc 各26页通过。最终部署与公网结果见下文。真实微信登录、真实支付、手机设备麦克风和人工目标用户验收独立记录，不由内测 mock 或 Chromium 自动化代替。
