# #152 用户查询与项目服务（本地工程）

2026-11-02：用户列表、产品账号详情和项目服务详情使用 Vben Page 与 Ant 组件，入口为 `/admin/users`、`/admin/users/:id` 和 `/admin/users/projects/:projectId`。服务表单嵌入具体项目，自动带入项目和绑定版本；不提供独立工单工作台、封禁、合并或账号扩展功能。

## 查询与备注契约

- 所有本票查询和备注沿用 `care:write`，不增加角色权限。`GET /v1/admin/users?q=&pending=true|false&page=1&pageSize=20` 返回 `{items,total,page,pageSize}`，页长最多 100；产品账号与无账号讲述者分别作为 `account`/`narrator` 行。按记录时间、ID 倒序，在完整数据集内搜索账号、订单、项目、讲述者和书名；没有昵称或手机号的账号使用实际编号。
- 账号关联包括发起人、当前讲述者绑定、申请人/换绑目标和历史换绑，避免换绑后隐藏原有服务关系。无账号讲述者行进入其项目。待处理根据项目上真实 `open`/`verified` 的导出、换绑、撤回/删除和校对请求发现，不要求支付订单。
- `GET /v1/admin/users/:id` 返回账号创建时间、实际已有登录方式、全部关联项目/订单、服务申请摘要、追加备注及最近 100 条本账号审计。`GET /v1/admin/users/projects/:projectId` 返回参与身份、实际来源、关联订单/生产单、全部适用服务摘要、当前告知版本和本项目审计，不读取故事正文或私人文件。
- `POST /v1/admin/users/:id/notes` 要求 Origin、CSRF 和 `Idempotency-Key`，正文 1–2000 字。相同账号/经办人/key/正文只追加一次，正文变化返回 409；服务端保存经办人/时间，备注与审计同事务提交。数据库变更为 `20261102130000_admin_user_queries`，备注禁止更新。
- 已有本人核验、换绑、完整导出、撤回/删除及限时故事校对复用原公开命令、当前授权和版本条件。资料正文只在原限时授权下加载，新校对稿仍经本人确认。项目操作写入各自项目审计；账号备注只关联产品账号。

## 内部验收与完整导出

CompleteExports 仅在原隔离合成配置或现有受控 `internal-acceptance` 书稿/录音/验收配置下装配。保留非生产环境、候选书稿、私有对象、当前授权、确定版本、撤回及删除限制，不放开整组生产/质量模块。

完整导出通过现有 `readProjectAdmissionIn` 读取实际准入，因此已付款和无支付订单的内部项目均可使用本人领取流程。实际内部/受控 paid-e2e 来源由客服人工核验受理，处理人是实际受理管理员，截止时间由本次受理明确登记；用户端 `service.within/ownerRef/calendarRef` 为 null，不制造 D06 数字时限、销售工作日历或商业负责人。已审商业快照仍执行原 D06 校验。申请、受理和替代交付证据必须匹配当前快照告知及 `synthetic:`/`internal:` 范围。

无个人账号的讲述者保留请求与待办入口；只有实际快照具备替代接收人身份核验流程、本人确认渠道及交付渠道时，才显示原受控替代交付流程。缺失时明确显示“当前不能受理或领取”，不默认把资料交给付款人。无订单项目保持无付款、`physicalProduction:false`，不生成首本/生产权益。

长期服务和已完成资料包持续领取不变；本人授权、客服私人领取权限、会话和文件能力仍限时。离开详情、退出或失权后清理私人视图，迟到故事、包和删除清单不能恢复旧操作目标。
