# 首页赠礼称呼带入套餐页修复

2026-11-03，基于 main `c24be14b60a10636358b448943b6fcc3bbeb00b9`。

## 问题与修复

公网 `GET /recipient-types` 当前返回空目录。首页已有“送给妈妈”“送给爸爸”入口，但套餐页原先只在服务端目录中匹配传入称呼；匹配不到时清空选择，导致用户需要重新输入。

套餐页现在优先选择目录中匹配的关系；没有匹配项时，将首页传入称呼交给现有自定义称呼校验，填入输入框并选中。空的预设关系区域不渲染。服务端关系目录、价格、购买条件和授权规则继续使用现有接口，不生成全局关系或伪造关系 code/revision。
