## 验收条件

- [ ] 地址→确认制作→制作进度→寄出→送达对应画板，键盘和安全区不挡主操作。
- [ ] 复用真实首本权益、当前就绪 PDF、地址校验和权限；不恢复本人/双方确认、逐页勾选或手写门槛。
- [ ] 提交未知先查原操作，重复提交不复制权益/生产单；已提交展示当次固定版本。
- [ ] 确认取消后才允许修改重提；后续新稿不覆盖正在制作文件，物流由真实状态驱动。
- [ ] 本票全部主责画板完成设计与原生 UI、交互对照，记录 390px/320px、真实入口、截图与差异处理；不留死入口或用样例数据冒充业务。
- [ ] 实现、相关检查、原生验证及外部待验分别记录，改动与测试只覆盖本票实际边界。
