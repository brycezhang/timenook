## 流程与页面

| 主流程 | 展示内容 |
| --- | --- |
| 子女购买 | 礼物与书籍效果、选择妈妈或爸爸、同一999元套餐、支付后自动建项目、可选资料修改、微信邀请与身份确认 |
| 父母讲述 | 来自谁的礼物、三步过程、知情参与、一次一个问题、点按录音、保存原声、可跳过的追问 |
| 故事确认 | 大字全文、原声入口、本人允许入书、补充讲述、子女校对、改稿重新确认 |
| 成书预览 | 唯一书封、目录、内页节选、真实示例页数、完整书稿、本人内容确认、子女排版与地址确认、首本无需再付费 |

P01首页在390×844首屏内展示书籍效果、999元含一本实体书和两个赠礼入口。P02随对象显示套餐；P03用默认书名建立项目，直接进入邀请；P08是可跳过的资料修改状态。N01将赠礼动机、三步说明与授权放在同页。B02提供完整书稿前的内容概览，B04/B10明确已付与首本制作权益。

47类页面与状态通过92个演示画板呈现，共253处点击或定时交互、9个流程入口。由于当前 Figma 套餐不支持所需的变量切换，爸爸演示由同一结构生成45个文案变体，位于画布右侧；这不代表新增产品页面或两套业务。实现时共用路由和组件，只保存赠礼对象字段。N03–N06是同一个采访页的不同状态。

已购用户的产品默认入口为项目主页；原型各流程使用不同阶段的演示数据，购买成功、已有三篇故事和印刷完成不表示真实数据自动增长。

## 视觉与适老交互

沿用奶油白 `#F7F6F3`、柠檬黄 `#E8F075`、墨黑 `#17140F`，录音中使用红色和文字状态。唯一书封使用浅色纸感、深色书名和金色线条。主界面正文不叠加在照片上。

画板390×844，主要正文20px、行高32px，按钮60px高，录音按钮116px。正文与操作使用 Noto Sans SC，书封及赠礼标题使用 Noto Serif SC。正文滚动时底部操作保持可见。父母端每屏突出一个任务：短问题、必要状态和主要操作；重复说明、零值统计和技术过程不常驻显示。故事正文完整保留，授权与入书确认不省略。

首页[书籍展示图](assets/gift-book-v2.png)由内置图像工具生成，标有“效果示意”，不是客户案例或实物打样。生成提示词及使用说明见[素材说明](assets/prompt.md)。界面其他主体保持可编辑文字、Auto Layout、组件实例与矢量。

## 演示范围

人物、故事、地址和照片均为演示资料。微信支付、录音、分享、授权返回与生产状态是交互模拟；表单预填，不模拟键盘输入；原声展示播放状态，二维码为视觉示意。没有真实付款、采集声音、发送邀请或印刷订单。

书稿以3篇故事、12页展示完整预览结构，不代表上线书籍规格、最低篇数或页数。具体装帧、页数范围、期限、额度、配送和售后参数按PRD上线条件确定。生产周期按书稿锁定并审核后的实际规则公示。
