## 集成中修复

- WebKit 实际录音触发 IndexedDB `Error preparing Blob/File data`，改为将原始 MP3 字节和元数据一同提交，读取后恢复 Blob，刷新/重试沿用同一录音与摘要。
- 照片起点首篇故事保存同采访的确定照片快照；后续照片说明变化不覆盖已保存版本。
- 故事原声按版本 manifest 的 `intentId` 访问录音入口，避免把 `RecordingClip` ID 误作 `RecordingIntent` ID；实际解码/播放验证，不仅检查区域可见。
- 产品构建补齐编码器许可与对应源码；构建测试校验公开文件与排除原型认证控制。
- CI 原生构建断言曾把正式条款中的“网页同号账号”解释误判为演示入口，现保留全部演示标记/路由禁用与 `web-view` 禁用，同时允许条款解释已确认的双端政策。
