# T04 · 验证照片处理、固定 PDF 与纸面原声入口

GitHub：[#5](https://github.com/brycezhang/timenook/issues/5) · 状态以 GitHub 为准。
阶段：S0

## 交付结果

以合成或已授权内容生成一份候选生产文件，完成图片方向/清晰度检查和实体打样扫码。

## 验收条件

- [ ] 原图、预览图及印刷图分别保存；覆盖 EXIF 方位、候选 HEIC、低清提示及解码像素/内存上限。
- [ ] 固定 Chromium、字体与候选模板；验证中文长段落、分页、目录收敛、图片和二维码，无缺字或截断。
- [ ] 记录尺寸、装帧、色彩、页数、出血、字体许可、最终 PDF hash 和印厂接收结果，冻结 D01。
- [ ] 用测试身份验证纸面码→受控入口→对应测试原声；记录 iOS/Android 扫码及正式路由限制，区分电子文件与实物证据。

## 实现边界

只验证一套图片处理、排版、字体和二维码路径；T16/T20/T21 复用实现与适用证据，保留 D01 和实物检查，不预建多模板或排版编辑器。
