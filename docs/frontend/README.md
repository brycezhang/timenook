## 运行

```bash
npm install
npm run dev
npm run check
npm run check:native
```

浏览器打开 http://127.0.0.1:5173，首页可选择妈妈/爸爸体验购买，或点击“先看看，一本故事书的模样”进入包含三篇故事的示例项目。右上角胶囊可打开页面导航；桌面左下角可切换320、375、390、430宽度。

已有项目默认进入当前项目；再次购买从“我的 → 再送一本”返回赠礼首页。每次演示购买创建独立项目，在“我的 → 我的项目”切换；原项目的故事、原声、照片与确认状态保留。旧版单项目数据自动兼容读取，下一次写入时保存为项目列表。“重新体验”仅清除当前项目，其他项目保留。

项目主页顶部显示品牌“时光里”；项目、成书、我的页面的底部首项统一显示当前书名，随项目切换和书名修改更新，过长名称省略显示。项目管理入口使用“我的项目”“项目资料”，成书介绍使用“故事书”。

原生端先执行 `npm run build`，在微信开发者工具导入项目根目录。`project.config.json` 指向 `dist/miniprogram/`；游客AppID用于本地开发，真机预览需替换成有权限的小程序AppID。修改源文件后重新构建。不要直接修改 dist。

`check:native` 默认查找 macOS 官方微信开发者工具的 `wcc-exec` 目录，其他安装位置通过 `WECHAT_COMPILER_DIR` 指定。这个命令仅本地编译，不上传代码。

## 工程结构

- `miniprogram/pages/`：每页独立的呈现和事件处理。
- `miniprogram/domain/model.ts`：项目、故事、录音、版本确认及印刷门槛。
- `miniprogram/services/store.ts`：本机持久化与导航；未伪装服务端请求。
- `miniprogram/services/recorder.ts`：原生录音生命周期、文件落盘、失败重试及中断处理。
- `miniprogram/styles/tokens.wxss`：色彩；`app.wxss` 提供共用按钮、面板、页脚等样式。
- `preview/`：仅供桌面检查的WXML/WXSS渲染及wx适配层，复用页面TypeScript。不会进入原生小程序包。浏览器录音通过MediaRecorder，文件存IndexedDB；不使用伪造的录音进度。
- `tests/`：确认版本约束、地址校验、权限失败、延迟录音停止及保存失败恢复测试。

## 明确边界

这是可运行的前端交付，尚未完成以下真实服务的验收：微信登录与权限绑定、支付、跨设备邀请、音频上传与转写、AI整理、云端存储、最终分页PDF、有效原声二维码、印刷生产、物流与客服。

微信录音调用真实 `RecorderManager`，浏览器调用真实麦克风。此次没有采集用户声音，也没有进行微信真机录音/中断验收；录音保存与失败恢复使用隔离的API替身测试。设备权限、来电/切后台、存储上限与弱网仍需在接入真实AppID后验收。

所有确认只保存在当前设备，不构成服务端授权凭证。示例故事与真实录音保持分离，绝不将示例文字声称为录音转写。当前书稿是完整内容阅读视图，不能作为最终印刷PDF；界面已明确标注。

JSON导出包含故事与资料索引，不包含音频、照片二进制；原声音频可逐段导出。音频/图片保存到本机不等同云端备份。尚未实现完整资料包与服务器删除流程。

人物和书籍素材均为内置 imagegen 生成的效果示意，文件已保存在项目中；不是真实客户案例或打样。使用场景与生成提示词见 [素材记录](asset-prompts.md)。
